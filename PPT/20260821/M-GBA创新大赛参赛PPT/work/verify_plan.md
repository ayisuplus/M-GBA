## 一、执行摘要

M-GBA（Multi-scale Graph Biological Architecture）是一个用可运行计算模型表达生命状态从微观调控到宏观表型逐层生成的跨尺度计算架构。项目以“L0 基因/转录调控 → L1 分子/蛋白状态 → L2 细胞个体行为 → L3 组织、环境场与动态拓扑 → L4 有机体宏观表型”五层纵向递进为核心，主生成流只允许在相邻层之间发生，禁止跳层读取“上帝参数”，从而把“局部规则如何跨尺度累积为整体行为”这一科学问题变成可运行、可复现、可审计的计算实验。

项目已完成契约演示器、五层参考模型、多速率运行器、冻结实验矩阵、报告重建链与真实数据锚定场景包，当前自动化测试 298 项，累计 29 份架构决策记录（ADR）留痕。以 CAR-M（工程化巨噬细胞）细胞治疗为锚定场景，项目用 752 个 TCGA-BRCA 样本的去标识聚合 profile 贯通 L0→L4，并完成空间扩展、机制审计与状态条件序列干预实验。

本项目的差异化在于“诚实的可计算性”：所有模型均为可替换的 reference model，负面基线原样保留，科学表述按五级术语分级不越级宣称。这与国务院《关于深入实施“人工智能+”行动的意见》将“人工智能+”科学技术列为首要任务[1]、广东省将生命科学列为 AI 赋能科研七大重点领域[2]、北京市提出构建跨尺度生物分子设计、生成、模拟与优化模型体系[3]的政策方向高度契合。


## 二、背景与问题定义

### 2.1 生命科学的跨尺度鸿沟

生命现象横跨基因、分子、细胞、组织到有机体多个尺度。湿实验范式存在三重结构性痛点：跨尺度观测难（难以在同一实验中连续追踪微观调控到宏观表型的生成过程）、周期成本高、干预不可遍历（剂量与时序等策略组合数量爆炸）。现有端到端计算模型则存在黑盒不可解释、缺层间审计（无法在轨迹中定位每次跨层转换）、宏观答案直写（宏观指标被直接编码进目标函数而非由局部交互生成）等问题，难以获得科研与监管的信任。


### 2.2 政策窗口

国家与地方政策密集部署“人工智能+科学技术”：国务院文件将“人工智能+”科学技术列为首要任务[1]；广东省《加快推动人工智能赋能科学研究行动方案（2026—2030年）》将生命科学列为七大重点领域之一[2]；北京市实施方案明确提出“构建跨尺度生物分子设计、生成、模拟与优化的模型体系”[3]。2026 科学智能大会上，鄂维南院士指出 AI for Science 已进入“下半场”，重心从方法探索转向科研体系的系统性变革与干湿闭环[4]。M-GBA 的“在硅预筛 + 可审计证据链”正对准这一范式需求。


## 三、产品与技术方案

### 3.1 五层纵向生成架构

| 层级 | 回答的问题 | 最小输出契约 |
| --- | --- | --- |
| L0 基因与转录调控 | 细胞具有什么潜在能力，哪些能力正在表达？ | TranscriptState |
| L1 分子与蛋白状态 | 当前表达形成了哪些受体、酶和信号能力？ | MolecularState |
| L2 细胞个体 | 分子状态如何改变细胞感知、状态转换和行为？ | CellState / CellAction |
| L3 组织与语义拓扑 | 局部细胞行为如何改变相互作用网络和微环境？ | TissueState / 场 |
| L4 有机体宏观表型 | 组织状态最终形成什么整体稳定性、功能或失衡？ | OrganismState |

硬约束：每层只消费下层显式输出，L2 不得绕过 L1 直读基因值。多智能体只是 L2 的细胞表达方式，STEN 只是 L3 的语义通信子系统，二者不取代项目本体。


### 3.2 三类信息流

上行生成流（L0→L4）是项目主线；层内交互流容纳多智能体（L2）与 STEN（L3）；下行约束流中 L4 只改变环境压力与资源边界，慢于上行、可审计、受安全屏障限制，从不指定 L2 动作。


### 3.3 可控替换的层模型库与双基线哲学

每一层保留永久基线，新模型只作层内替换且契约不变：L2 提供主动推理（预期自由能最小化）与连续潜状态“虚拟细胞”两种可选策略，永久基线为五态规则状态机；L3 提供受治理动态拓扑与冻结权重 GNN 变体，永久基线为固定有向图；L0 提供种子化转录噪声与冻结权重 MLP 变体，永久基线为六节点确定性离散 GRN。任何新模型接入前必须回答六个准入问题（属于哪一层、替换哪个基线、回答什么研究问题、用什么指标判断、失败能否移除、用户能否解释），失败可移除而不破坏其他层。


### 3.4 CAR-M 真实数据锚定与因果空间扩展

CAR-M 场景包由 752 个 TCGA-BRCA 样本的 GAT 预测去标识聚合构成（high/low/normal = 323/273/156，代理标签而非临床真值），以 63 个 Cell 的固定图贯通 CAR 信号程序 L0→L4。可选因果空间 L3 将归一化坐标、12×12 压力/资源/信号场与半径邻域纳入正式 trace 与 checkpoint。外部空间锚定已预注册：Wu/Swarbrick Visium 三文件与 Jackson IMC 两文件，Rights 核验为 CC BY 4.0 与 CC BY 1.0 Generic，最小包约 241 MB。


## 四、实验证据与诚实治理

### 4.1 跨尺度传播与机制审计

WP8 实验验证一次 L0 修复表达敲低能够依次改变 L1、L2、L3、L4，且每次跨层转换可在轨迹中定位。CAR-M 空间 L3 的 2×2×2 机制审计显示描述性主效应：场耦合 0.048720、空间邻域 0.025588、移动 0.000898，全关与仅移动均为零效应负对照——当前杠杆点在场耦合与邻域，而非移动。


### 4.2 对照替换与参数标定

配对对照矩阵强制两个 runner 仅在单一层不同，实现跨层效应归因。L2 规则参数标定采用预注册搜索（sha256 种子扫描 + 坐标细化，参考向量恒为首评点），训练得分由 0.2076 提升至 0.5927，四档 holdout 全部提升，判定 generalized。E3 多种子噪声集合按预注册判据分级，出现 emergence candidate 时严格按五级术语表述，不越级宣称涌现。


### 4.3 可观测、可复现与治理体系

逐 tick trace 记录跨层转换；JSON checkpoint 支持位级断点恢复；SHA-256 manifest 固定配置与代码版本；raw-only 报告链从冻结 artifact 字节级重建 CSV/SVG/HTML；相同种子精确复现。诚实治理包括：默认 100 tick 结局为 FAILED 的负面基线原样保留、预注册判据与 holdout 冻结、五级科学表述分级（contract demonstrator → validated result）、29 份 ADR 留痕、数据登记 fail-closed 门禁。

## 六、竞争分析与差异化

相较于端到端黑盒模型，M-GBA 的层间契约与逐层审计提供可解释证据链；相较于传统 Agent-based 模型，M-GBA 以正式 DTO/Protocol 冻结层间接口、以配对对照矩阵量化单层贡献、以预注册判据约束表述。项目不追求“更大模型”，而追求“可信的跨层证据”。
