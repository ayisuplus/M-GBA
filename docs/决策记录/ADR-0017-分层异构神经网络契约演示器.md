# ADR-0017：分层异构神经网络——冻结权重契约演示器（L0 MLP + L3 GNN）

> 状态：Accepted
> 日期：2026-08-20

## 背景

1. 用户提出：全用 Transformer 算力拖不动，能否按层使用不同神经网络（基因→ANN、蛋白质→CNN、细胞交流→GNN）以降低算力消耗，并明示可以纠正其映射。
2. **算力不是当前绑定约束**：本项目是纯标准库的确定性参考模型（4–63 个 Cell、6 个抽象基因），全量测试在 CPU 上秒级完成；真正的绑定约束是 AGENTS §6 的确定性、可审计性与零依赖（`pyproject.toml` 的 `dependencies = []`，重量级依赖需显式授权）。因此"分层异构"的正当动机不是省算力，而是**归纳偏置与数据结构对齐**：每层的数据形态决定合适的网络族。
3. 对用户映射的诚实修正：
   - L0 是 6 维小向量 → MLP（用户"基因→ANN"在此命中）；
   - L1 是 6 物种粗粒度分子向量，无空间/序列轴，CNN 的平移不变局部核没有作用域 → 不适用，同样应给 MLP，本轮不新增（避免无动机的重复）；
   - L2 已有规则状态机（ADR-0004）与主动推理（ADR-0013）两种 `CellModel` 实现，再叠 ANN 策略是重复；
   - L3 组织是固定有向图 → 消息传递 GNN（用户"细胞交流→GNN"在此命中）。
4. 文献融合：PhysiCell 2024 的场级耦合分层思路支持"每层按其数据结构选型"；GNN 组织学建模有 Brussee 2025 与 Ali 2025（PMC12462520）的先例；MANTA（arXiv:2607.28527）的框架层治理思路与本仓库"层协议冻结、层内模型可换"一致。这些是先例支持，不构成任何生物真实性宣称。
5. 仓库内不存在监督目标或训练数据（ADR-0005 因此拒绝 GNN 进 WP5），AGENTS §2 的新能力门禁不允许"先训练再解释"。

## 决定

1. 新增 `mgba.neural` 纯标准库神经基元（零依赖、无全局随机状态）：
   - `seeded_matrix(seed, salt, rows, cols)`：逐元素由 $\mathrm{sha256}(seed\|salt\|i\|j)$ 派生独立 RNG 流，$w_{ij}\sim\mathcal{U}(-s,s)$，$s=1/\sqrt{n_{in}}$（Xavier/Glorot 式 fan-in 界）；
   - `mlp_forward(x, weights, activation)`：hidden 层 tanh、输出层恒为溢出安全 sigmoid（保证 $[0,1]^n$，与 L0/L3 边界 DTO 的单位区间契约对齐）；
   - `message_passing_step(x, edges)`：入邻均值消息 $m_i=\frac{1}{|N^{in}(i)|}\sum_{j\to i}x_j$（无入邻居为零向量），未知端点/自环/重复边 fail-fast。
2. 新增可选 L0 `GenomeModel` 实现 `NeuralGrnModel`（`mgba.layers.l0_neural`）：输入 $u=(x(t-1), g, d)\in[0,1]^{13}$，目标 $y=\sigma(W_2\tanh(W_1 u))\in(0,1)^6$，自然更新沿用参考族 $x_i(t)=(1-\lambda)x_i(t-1)+\lambda y_i$；扰动硬钳制仍在自然计算之后，语义与 `DiscreteGrnModel` 一致。
3. 新增可选 L3 `TissueModel` 实现 `GnnTissueModel`（`mgba.layers.l3_gnn`）：节点特征 $x_i=(\sigma_i,r_i,s_i,\mathrm{sec}_i,\mathrm{rep}_i,\mathrm{cons}_i)$（上一步节点 3 字段 + 当前动作 3 字段），消息 $m_i$ 为入邻均值，更新 $h_i=\sigma(W_{self}x_i+W_{neigh}m_i+b)\in(0,1)^3$ 写回 $(stress, resource\_level, signal)$；聚合复用冻结公式，`tissue_damage` 沿用 ADR-0005 的 0.6/0.4 权重（内嵌于 `GnnTissueConfig`，不读 `TissueConfig`）。非空 `FeedbackConstraint` 显式抛错，与 `TissueEnvironmentModel` 一致，不进入 E4 反馈闭环；GNN 从不修改拓扑。
4. **冻结权重而非训练**：两个变体的全部权重由显式 `weight_seed` 确定性派生，逐次前向、无训练循环；config 与 seed 进入各自状态的 source digest 哈希链，每次权重抽取可审计。
5. 新增 `mgba.neural_experiments` + `mgba neural-experiment`（E2 式单层替换配对对照）：构造器强制两 runner 的 `model_versions` 仅在 `changed_layer ∈ {L0, L3}` 不同；复用 WP8 配对比较指标与 artifact 协议。新增 `scripts/synthetic_neural_benchmark.py`（复用共享数据集生成器）。
6. 两个变体都不从 `mgba.layers.__init__` 再导出（包 `__init__` 再导入依赖 experiment 的模块会循环导入）；用户代码直接从模块路径导入。确定性参考模型保持默认与永久基线。

## 结果

- 分层异构从直觉变为可执行对照：L0 MLP 与 L3 GNN 各自满足冻结的五层协议，轨迹差异由 `neural-experiment` 用配对指标量化，而不是由故事宣称。
- 冻结基线不变：默认链 100-tick 身份 `mgba-06a3c6124501f1d6` / `4b008f6c…` / `failed` 由测试门禁固定；新变体全部 opt-in。
- 科学边界：这是 `contract demonstrator`（AGENTS §4 第 1 级），只验证"神经形态层能遵守契约"与"替换差异可测"；不宣称神经真实拟合、不宣称训练能力、不宣称算力优势的实测证据（仓库为 CPU 秒级 stdlib 负载，无此瓶颈）。

## 回退

删除 `neural.py`、`l0_neural.py`、`l3_gnn.py`、`neural_experiments.py`、对应配置/CLI/测试/基准脚本与文档条目即可回到 ADR-0016 状态；既有层模型与实验协议不依赖本次新增代码。
