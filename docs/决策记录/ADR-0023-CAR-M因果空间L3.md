# ADR-0023：CAR-M 可检查点因果空间 L3

- 状态：已接受并实现
- 日期：2026-08-21
- 所属层级：L3 Tissue / Environment / Topology
- 关联：ADR-0005、ADR-0014、ADR-0022

## 1. 问题

ADR-0022 把旧 `D:\car-m-virtual-cell` 的双画布、场叠加和实验比较交互迁入只读观察层，但观察台中的坐标和热图只是由正式 L3 节点值派生的显示投影，不进入下一 tick。它提高了可解释性，却没有回答更深的研究问题：

> Cell 的局部移动、空间场异质性和邻域变化进入因果热路径后，会怎样改变 CAR-M 的跨尺度轨迹与 L4 表型？

直接搬运旧 TypeScript ABM 不可接受。旧实现把移动、10 通道场、复制、吞噬和 GAT 预测混在一个运行时中，空间状态没有进入当前 Python runner 的正式 checkpoint，也会同时改变 L2/L3 和数据语义。

## 2. 决策

新增一个可选、确定性、只替换 L3 的 CAR-M 空间 reference model：

1. 保留原 `TissueState` 字段集不变；新增其子类型 `SpatialTissueState`。
2. `SpatialTissueState` 额外保存每个 Cell 的归一化二维坐标、完整行优先三通道场网格和由空间半径生成的有向边。
3. 空间状态不存在模型对象的隐藏内存；下一 tick 只消费上一正式 `SpatialTissueState`，因此 checkpoint 落盘恢复与连续运行严格一致。
4. 每 tick 的因果次序固定为：上一场驱动存活免疫 Cell 的确定性移动 → 当前 L2 动作写入压力/资源/信号场 → 新坐标生成空间邻域 → 空间邻域和局部场共同更新正式 L3 节点 → 既有 L4 观察器消费 `TissueState` 公共字段。
5. 固定图 `CarmTissueModel` 不修改、仍是默认与永久基线；新命令 `mgba carm-spatial-experiment` 做同 seed 配对对照，构造器强制两个 runner 只在 L3 模型版本不同。
6. 除 WP8 家族的逐层距离、传播 tick 和有向 L4 差值外，空间条件额外报告平均位移、逐 tick 边周转率、终末场异质性和终末邻格梯度。

## 3. 新能力准入回答

1. **属于哪一层？** 只属于 L3；L0/L1/L2/L4、Runner 时钟和相邻层协议不变。
2. **增强哪个基线？** 增强 CAR-M 固定有向图 L3；固定图模型永久保留。
3. **回答什么问题？** 判断显式空间状态是否会改变局部微环境、跨层传播时序和 L4 轨迹，而不是只让画面更像模拟器。
4. **如何判断有效？** 同 seed、同 L0/L1/L2/L4 的固定图/空间配对；检查 L3/L4 效应、位移、边周转、场异质性/梯度、确定性与 checkpoint 精确恢复。
5. **失败时能否移除？** 可以。删除空间模型、子类型恢复分支、命令与配置即可；固定图 CAR-M 和冻结矩阵不依赖它。
6. **能否解释原理和局限？** 可以。它是单位方形上的确定性移动、邻格混合、局部源汇与半径邻域；参数无真实单位、未拟合，不是物理扩散或临床模型。

## 4. 借鉴与拒绝迁移

从旧项目只借鉴“显式位置—局部场—邻域—宏观统计”的问题分解。以下内容不迁移：

- 10 通道生物场与连续物理单位；
- 随机移动、复制、吞噬和死亡事件；
- GAT 直接驱动 Cell 的热路径；
- React store 或 Canvas 作为模型状态；
- 任何未进入 manifest/checkpoint 的隐式随机源。

第一版只保留现有正式三通道：压力、资源、信号。它们是无量纲 reference 变量。

## 5. 兼容性与 checkpoint

不向基础 `TissueState` 增加可选字段，因为那会改变所有冻结 artifact 的 JSON 和 digest。只有空间运行实例化 `SpatialTissueState`；checkpoint loader 根据完整空间字段集恢复子类型，缺任一字段即 fail-closed。固定图运行仍序列化为原字段集。

## 6. 科学边界

- 该模型是 `reference model`，不是肿瘤组织重建或连续偏微分方程求解器。
- 坐标没有微米单位，tick 没有真实时间单位，混合/移动系数没有实验标定。
- 空间条件优于或劣于固定图都不能解释为更真实；只能说明在当前规则中加入空间状态改变了轨迹。
- 现有 TCGA profile 仍是群体代理锚点，不提供空间真值。
- 在外部空间组学/成像数据、多个随机过程、预注册统计与层级消融之前，不宣称组织涌现、疗效预测或临床有效性。

## 7. 回退路径

默认 CAR-M 命令和冻结 `carm_vertical_slice.json` 不引用空间配置。若空间模型失败，继续使用 `CarmTissueModel`；空间 artifact 由独立 schema 和目录保存，不影响 v0.2 冻结身份。

## 8. 验证门禁

- 空间 DTO 的完整、排序、范围和网格覆盖校验；
- 相同输入与显式 seed 的轨迹确定性；
- 固定图条件仍输出基础 `TissueState`，无空间 JSON 字段；
- L0 群体扰动能够经空间 L3 改变 L4；
- 运行中坐标、场和边产生可测变化并进入 source digest；
- checkpoint 保存、加载和分段续跑与一次性运行严格一致；
- 配对实验构造器强制只替换 L3；
- 全量回归和最低本地门禁继续通过。
