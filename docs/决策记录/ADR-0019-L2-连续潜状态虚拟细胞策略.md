# ADR-0019：L2 连续潜状态"虚拟细胞"策略（Latent Cell Policy）

> 状态：Accepted
> 日期：2026-08-21

## 背景

1. 项目所有者提出将 M-GBA 与 AI 虚拟细胞（AIVC）研究结合，在细胞层加入更多细节与更好的架构；资源授权边界为**纯本地、零下载**（排除外部数据集与预训练权重）。
2. 2025–2026 AIVC 前沿调研（检索时间 2026-08-21）：
   - Arc Institute 的 STATE 模型（2025-06 发布，[bioRxiv 2025.06.26.661135](https://www.biorxiv.org/content/biorxiv/early/2025/06/27/2025.06.26.661135.full.pdf)）：多尺度架构 = 1.67 亿观测细胞训练的**细胞状态嵌入模型** + 超 1 亿扰动细胞训练的**扰动转移模型**，预测干细胞/癌细胞/免疫细胞对药物、细胞因子、基因扰动的转录组响应（[Arc 官方说明](https://arcinstitute.org/news/virtual-cell-model-state)）。
   - Tahoe-100M 扰动图谱（2025-02，Arc Virtual Cell Atlas；[2026-01 扩展合作](https://arcinstitute.org/news/tahoe-arc-biohub)）：AIVC 的数据基座范式——因果预测能力来自大规模干预型数据。
   - scGPT/Geneformer 等单细胞基础模型谱系与中文综述（如《中国工程科学》AIVC 综述）确认该范式的共同结构：**连续细胞状态嵌入 + 条件转移算子 + 任务读出**。
3. 五层映射结论：AIVC 的建模对象是**细胞内在状态**，在 M-GBA 中落在 L0/L1（架构设计 §3.1/§3.2 已预留"转录组数据驱动模型/真实基因基础模型"替换位）；AIVC 不做多细胞群体、L3 环境场/拓扑、L4 聚合与慢反馈——那正是 M-GBA 的差异化位置。因此本 ADR 不把任何外部模型接入热路径（那会违反禁止跳层与零下载约束），而是把 AIVC 的**架构类**（连续潜状态 + 结构化转移算子 + 读出头）实例化为 L2 层内 `CellModel` 变体。
4. 内部动机：WP8 显示 L2 静态替换产生最大终点差异，L2 是当前杠杆点；ADR-0013 在"决策规则"轴上加入主动推理；本 ADR 在正交的"**状态表示**"轴上加入连续潜状态变体。规则状态机保留为默认与永久基线。
5. 协议约束推导（决定设计的关键）：`CellModel.step` 的唯一历史载体是正式 `CellState` DTO（相位 + activation/viability/stress_load）；checkpoint 只序列化正式 DTO，恢复时模型实例重建——任何隐藏逐细胞记忆都会在恢复后静默失同步。因此**潜状态必须每 tick 从正式 CellState 确定性重建**；这恰好对应 AIVC"嵌入是细胞状态的函数"的语义，并保持断点恢复不变量位级不变。

## 决定

1. 新增 `mgba.layers.l2_latent.LatentCellModel`，实现既有 `CellModel` 协议；`configs/layers/l2_latent_cell.json` 为独立冻结配置。规则状态机 `CellStateMachineModel`、静态基线 `StaticCellModel`、主动推理策略均不做任何修改。
2. 潜状态架构（全部纯标准库、确定性、冻结权重，复用 `mgba.neural.seeded_matrix`，ADR-0017 基元）：
   - 输入向量 $u_t=(m_t,e_t,s_{t-1})\in[0,1]^{12}$：6 个 L1 分子种属 + 3 个局部环境场 + 上一 `CellState` 三标量（首 tick 取中性 0.5）；
   - 状态嵌入 $z^{prev}=\tanh(W_s s_{t-1})$，$W_s\in\mathbb{R}^{k\times3}$；
   - 泄漏递推 $z_t=(1-\lambda)z^{prev}+\lambda\tanh(W_{in}u_t+W_{rec}z^{prev}+b)$，$W_{in}\in\mathbb{R}^{k\times 12}$，$W_{rec}\in\mathbb{R}^{k\times k}$ 行 L1 范数缩放至 $\le1$ 保证 tanh 递推收缩，$\lambda=\text{leak\_rate}\in(0,1]$；
   - 相位读出 $\ell=W_{ph}z_t\in\mathbb{R}^4$，仅覆盖**非死亡四相**（quiescent/activated/repairing/stressed），argmax 平局按冻结顺序确定性裁决。
3. 死亡永不由读出产生：沿用与规则/AIF 同族的硬护栏（`viability <= death_viability_threshold` 或 `death_drive >= death_drive_threshold`），DEAD 吸收态与凋亡动作逐式一致。随机冻结权重因此不可能在极端输入下制造全死亡或死而复生的病态轨迹。
4. 状态簿记（活力、压力负荷、激活驱动）与动作方程（按相位分泌乘子、消耗速率、仅 REPAIRING 的修复努力）与规则模型逐式一致——E2 式配对替换只隔离"**相位由连续潜状态表示产生，而非固定阈值优先级**"这一个变量。
5. 权重全部由配置中的 `weight_seed` 经 `seeded_matrix` 确定性派生并在构造时冻结；**不训练、不拟合、无外部权重文件**。配置（含 `latent_dim`、`leak_rate`、`weight_seed`）进入 `CellState` source digest 哈希链，每次权重抽取可审计。
6. 新增 `mgba latent-experiment` CLI 与 `mgba.latent_experiments`：同场景同种子配对运行 `rule_policy` 与 `latent_cell_policy` 两个 runner，复用 WP8 `_compare_runs` 逐层距离、L4 有向差值与首次传播 tick；矩阵构造器强制两 runner 仅 L2 版本不同；artifact schema `mgba-latent-artifact-0.1`，append-only。
7. 新增 `scripts/synthetic_latent_benchmark.py`：复用 `synthetic_feedback_benchmark.generate_dataset` 的确定性场景集，对每场景运行规则 vs 潜状态对照并汇总 CSV/JSON。
8. 新增 `tests/test_latent_cell.py`（17 项）：配置 fail-fast、数值极端（退化驱动、latent_dim=1/64、全泄漏）、死亡吸收态、读出永不选 DEAD、递推行范数收缩、确定性、契约（时间倒退/身份/类型）、**无隐藏记忆不变量**（同一正式 CellState 续跑与长轨迹逐字段一致）、配对矩阵不变量（L0 效应恰为零；L1 仅经相邻反馈 <1e-6；矩阵确定性；错误层替换拒绝；预算拒绝）。

## 结果

- L2 获得第三个策略实现，首次把"状态表示"从五相离散变量推广为连续潜向量，且规则基线原样保留；默认 `mgba run` 与全部冻结矩阵不使用该模型，无注入时所有 0.2.0 身份位级不变（`test_frozen_identity` 通过）。
- 默认演示场景配对矩阵（`latent-720e856b90c97b2b`，3 seed × 30 tick）：L0/L2/L4 层效应恰为 0，L1 ≤ 2.8e-12，L3 ≤ 1.3e-22；逐 tick 相位分歧仅 4/120 cell-tick（cell-a 2、cell-c 1、cell-d 1）；两条件结局均 `FAILED`。输入网格探针（135 组合）显示读出对输入敏感（tick-1 与规则一致 28、分歧 107），即**近零效应来自默认场景轨迹所访问区域的相位高度一致，而非读出退化**。
- 合成基准（24 行 = 4 场景 × 2 条件 × 3 seed）：calm 档潜状态条件终末稳态略低（0.156617 vs 0.157123）、炎症略高（0.494491 vs 0.494077）、终末活力略低（0.011033 vs 0.011880）；injury 档位级一致；severe/collapse 档两条件均饱和一致。**全部 24 次运行结局均为 `FAILED`**——按零/负面基线保留，未为制造差异调参。
- 科学等级不变（contract demonstrator，AGENTS §4 第 1 级）：冻结随机权重未训练，不宣称"虚拟细胞级真实"、不宣称优于规则基线；与 AIVC 的真实数据/模型对接（扰动图谱锚定 L0/L1）属后续工作，需独立的下载授权与 ADR。
- 测试总数增至 221 项（204 + 潜状态 17），AGENTS §7 三条门禁全部通过。

## 回退

删除 `mgba/layers/l2_latent.py`、`mgba/latent_experiments.py`、对应配置/CLI/测试/脚本与文档条目即可回到 ADR-0018 状态；规则状态机、主动推理策略与全部冻结基线不依赖本次新增代码。
