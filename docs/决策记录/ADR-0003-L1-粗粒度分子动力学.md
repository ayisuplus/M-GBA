# ADR-0003：L1 第一版粗粒度分子动力学

> 状态：已接受  
> 日期：2026-08-18  
> 作用范围：WP3 L1 Molecular / Protein reference model

## 背景与研究问题

当前 L1 把三个转录值原样复制为蛋白值，虽然阻止了 L2 直接读取 L0，却没有承担独立计算职责。WP3 要回答：

> 当 L0 表达经过显式翻译、降解和信号激活/抑制后，L1 是否形成可复现、可替换且不可被绕过的分子状态，并继续传递 L0 扰动？

本模型只升级 L1。L0 离散 GRN 和 L2–L4 规则基线保持不变。所有变量均为归一化粗粒度能力，不代表真实蛋白浓度、结合动力学、原子结构或临床指标。

## 分子状态

第一版 `MolecularState` 固定六个 `[0, 1]` 变量：

| L1 变量 | 直接 L0 来源 | 抽象含义 |
|---|---|---|
| `damage_receptor` | `damage_response` | 接收局部损伤/信号的能力 |
| `signal_protein` | `signal_expression` | 当前有效信号能力 |
| `repair_protein` | `repair_expression` | 当前修复能力 |
| `metabolic_capacity` | `metabolic_expression` | 当前代谢支持能力 |
| `death_effector` | `death_expression` | 当前死亡执行倾向 |
| `feedback_inhibitor` | `negative_feedback_expression` | 当前信号抑制能力 |

L2 第一版仍只消费 `signal_protein`、`repair_protein` 和 `metabolic_capacity`；新增死亡与受体状态将在 WP4 Cell 状态机中正式使用。L1 不读取 `Genome`、组织状态或 L4 指标。

## 更新方程

对除信号蛋白外的分子量 `p_i`：

```text
p_i(t+1) = (1 - degradation_i) * p_i(t)
           + synthesis_i * transcript_i(t)
```

为保证输入和上一状态均在 `[0,1]` 时输出天然有界，配置必须满足：

```text
0 < synthesis_i <= degradation_i <= 1
```

这是一阶翻译—周转参考方程：第一项表达旧分子保留，第二项表达由转录状态产生的新分子。它不是质量作用动力学。

`signal_protein` 的有效转录驱动为：

```text
effective_signal(t)
  = clamp(
      signal_expression(t) * (1 - inhibition * feedback_inhibitor(t))
      + local_signal_gain * damage_receptor(t) * local_signal(t),
      0,
      1
    )
```

随后仍使用同一翻译—降解方程。由此得到最小的激活/失活机制：受体门控局部信号，反馈抑制物降低有效信号。所有节点同步读取 `t` 时刻分子状态。

## 固定参数

| L1 变量 | 合成率 | 降解率 | 无反馈平衡比例 `synthesis/degradation` |
|---|---:|---:|---:|
| `damage_receptor` | 0.30 | 0.40 | 0.75 |
| `signal_protein` | 0.35 | 0.45 | 0.78 |
| `repair_protein` | 0.30 | 0.35 | 0.86 |
| `metabolic_capacity` | 0.25 | 0.30 | 0.83 |
| `death_effector` | 0.25 | 0.45 | 0.56 |
| `feedback_inhibitor` | 0.30 | 0.40 | 0.75 |

`local_signal_gain = 0.5`，`feedback_inhibition = 0.4`。参数保存在独立 JSON 中，模型身份包含配置摘要。

这些值用于形成稳定且可解释的 reference trajectory，不来自实验数据拟合。

## 相邻反馈边界

`MolecularInput` 保存 Cell ID、逻辑时间、来源摘要和 `local_signal`。它代表未来 L2→L1 的相邻快速信号转导入口：

- 当前五层单步 Runner 将其固定为 `0`，即反馈关闭；
- L1 独立实验可以比较 `local_signal=0` 和 `1`；
- L1 不能自行读取 L2/L3 内部对象；
- 后续闭环只能由调度器把正式相邻输出转换成 `MolecularInput`。

## 时间和初始化

独立 L1 轨迹从全零分子状态开始，随后在固定或逐步变化的 `TranscriptState` 下更新。五层单步 Runner 使用 `previous_state=None`，等价于观察一次从零分子池开始的翻译；WP7 多速率 Runner 再持续传入上一 L1 状态。

## 验收与失败判据

固定配置必须满足：

1. 相同转录轨迹和输入产生完全相同的分子轨迹；
2. 所有分子状态始终位于 `[0,1]`；
3. 恒定转录输入运行 200 tick 后，最后一步最大绝对变化小于 `1e-8`；
4. 单独提高某一转录变量时，其直接分子输出单调上升；
5. 转录全部关闭后，从非零分子状态出发的所有分子量下降；
6. `local_signal=1` 相比 `0` 提高最终 `signal_protein`，而关闭入口时结果可复现；
7. L1 只接受 `TranscriptState` 和同 Cell 的 `MolecularInput`；
8. 缺失物种、未知转录来源、重复映射、非有限参数或 `synthesis > degradation` 必须失败；
9. 五层 Runner 中修复表达敲低仍先改变 L1 修复蛋白，再改变 L2–L4。

## 备选方案

1. 保留恒等映射：没有独立时间尺度和降解职责，拒绝作为默认模型，但保留为回归基线。
2. 布尔激活/失活：容易解释，但无法表达剂量和渐近周转，暂不采用。
3. 质量作用 ODE 或蛋白结合网络：需要更多未经验证参数和数值求解器，推迟。
4. 蛋白语言模型嵌入：不能直接提供当前场景所需的时间动力学，且会引入重量级依赖，拒绝进入 MVP。

## 影响、局限与回退

- `MolecularState` 增加受体、死亡执行和反馈抑制字段；原有三个 L2 输入字段保持名称不变。
- `MolecularModel` Protocol 增加上一 L1 状态和正式 `MolecularInput`。
- 恒等式 `StaticMolecularModel` 继续保留，可通过依赖注入恢复旧契约基线。
- 该模型没有真实分子单位、化学计量、结合常数、空间扩散或数据拟合，不能称为真实蛋白动力学。
