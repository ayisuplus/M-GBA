# ADR-0050：证据总览报告流水线契约

- 状态：已接受
- 日期：2026-09-12
- 影响范围：生成链外只读观察层；新模块 `src/mgba/evidence_report.py`，新命令 `mgba evidence-report`，产物落 `artifacts/evidence-report/`（或 `--output` 指定目录），测试落 `tests/test_evidence_report.py`
- 不影响：ADR-0001–0049 全部冻结产物与身份、五层契约、核心零依赖、参考基线；已有 `src/` 逻辑、`configs/`、已有 `artifacts/` 一律不修改（唯一例外：`cli.py` 按既有 `_register_*`/`_cmd_*` 模式追加新命令注册）。本 ADR 不重跑任何实验、不改变任何历史 verdict、不撤销或提升任何证据等级

## 1. 背景与研究问题

项目已积累多类互相独立的证据产物：WP8 冻结矩阵（ADR-0008/0009）、CAR-M 状态条件干预（ADR-0029）、空间锚定评估（ADR-0027）、AIVC 训练评估（ADR-0037/0039/0040/0046）、管线证伪对照（ADR-0048）、OE 成分外推边界（ADR-0049）、桥覆盖审计与效应稳健性探索性复分析（2026-09-11）、数据登记表（ADR-0021）。这些产物分散在不同目录、不同 schema 中，人工总览需要逐个打开 JSON；任何手工摘抄都无法证明展示与原始 artifact 一致。

本 ADR 要回答：

> 能否用一条命令扫描全部既有证据产物，归一化为统一证据模型，渲染成无 JavaScript 的静态中文报告，并保证同输入字节级可重建？

本报告是只读观察层，与 WP9 `reporting.py` / `run_report.py` 同类：不导入或调用任何 L0–L4 模型，不重跑任何实验，不修改任何 raw/derived artifact，展示层不构成新的科学证据。

六问：跨层基础设施（生成链外观察层，不属于 L0–L4 任何一层）；不替换任何基线，聚合展示对象为既有 artifact；研究问题为"分散证据能否确定性统一总览"；判断指标为 §6 验收清单（schema 校验、缺失降级、双跑字节一致、manifest digest 复核、负面结果标注）；失败时删除模块、命令、测试、产物目录与本 ADR 即可，核心链不变；报告每区块标注证据等级与来源路径，用户可直接追溯。

口径声明：

## 3. 五阶段流水线（冻结）

```text
collect → normalize → render → manifest → verify
```

1. **collect（收集）**：按 §2 枚举定位并读取输入文件；逐文件记录相对路径、存在状态与 SHA-256（缺失记 `null`）。schema_version 与枚举不符时按缺失降级处理并在区块注明实际 schema。
2. **normalize（归一化）**：把各输入映射为统一证据模型（§4）的 section 记录：`section_id`、`title`、`evidence_level`、`status`（`present`/`missing`）、`source_paths`、`findings`、`notes`。证据等级只使用 AGENTS.md §4 术语与 artifact 自身的 verdict/boundary 字段，由冻结映射表给出，展示不改变等级。
3. **render（渲染）**：从归一化模型渲染 `index.html`（中文、零 JavaScript、内联 SVG）、每区块独立 SVG 与 CSV。复用 `reporting.py` 的冻结调色板 `COLORS`、`svg_document`、`write_csv`、`label` 与 HTML 骨架风格。图表类型冻结为：条形/柱状图（区块 1/2/5/6/8/9）、森林图（区块 4，视觉重心）、色块表（区块 3/7）。
4. **manifest（清单）**：写入 `manifest.json`，登记产物 schema、输入文件 SHA-256 集合、每个生成文件的 SHA-256。
5. **verify（核验）**：`--verify` 子模式把完整流水线重跑进临时目录，与既有输出目录逐文件字节比对；文件集合或任一字节不同即失败并列出差异。

## 4. 产物 schema（`mgba-evidence-report-0.1`）

默认输出目录 `<artifact-root>/evidence-report/`：

```text
index.html                      # 统一中文报告，内联 SVG，零 JavaScript，零网络依赖
summary.json                    # 统一证据模型（schema_version=mgba-evidence-report-0.1）
manifest.json                   # mgba-evidence-report-manifest-0.1：输入与生成文件 SHA-256
training-evaluation.{svg,csv}
extrapolation-boundary.{svg,csv}
falsification-controls.{svg,csv}
effect-robustness-forest.{svg,csv}
wp8-matrix.{svg,csv}
carm-intervention.{svg,csv}
spatial-anchor.{svg,csv}
bridge-coverage.{svg,csv}
data-registry.{svg,csv}
```

`summary.json` 字段（全部 JSON 可序列化、确定性排序）：

- `schema_version`：恒为 `mgba-evidence-report-0.1`；
- `report_boundary`：只读观察层声明（逐字冻结）；
- `inputs`：§2 九类输入的相对路径、存在状态、SHA-256（缺失为 `null`）；
- `sections`：九个区块的归一化记录（顺序冻结为上表顺序），每区块含 `section_id`、`title`、`evidence_level`、`status`、`source_paths`、`findings`、`notes`；
- `derivation_notes`：展示性聚合公式逐条文字说明；
- `negative_findings`：全部 `failed` / `criteria_not_met` / No-Go / 未锚定条目的扁平清单（区块 ID + 原样数值），供页面顶部显著区直接引用。

缺失区块的 SVG/CSV 不生成；`index.html` 与 `summary.json` 始终生成并以 `status: "missing"` 如实登记。

## 5. 确定性与重建核验规则

- 渲染只消费归一化模型；模型中不含绝对路径、时间戳或环境相关值；所有路径以正斜杠相对路径记录。
- 相同输入连跑两遍（独立输出目录），全部生成文件必须字节级一致；`manifest.json` 逐文件 SHA-256 复核必须与磁盘实算值一致。
- `--verify` 对既有输出目录执行字节比对核验；核验结果（verified、mismatches）原样输出。
- 派生产物允许由构建命令覆盖（可重建），输入 artifact 永远不修改。

## 6. 边界声明（冻结）

1. 本流水线是**只读观察层**：不导入、不调用、不重跑任何 L0–L4 模型或实验协议；不读取 CellAction；不进入 tick 循环。
2. 展示不改变证据等级：每区块标注的等级（`contract demonstrator` / `reference model` / `探索性诊断` / `failed` / `No-Go` / 未锚定等）逐字来自 artifact 自身字段或 AGENTS.md §4 术语映射表，归一化不得升级或淡化。
3. **负面结果与 No-Go 状态必须原样显著标注**：KD 训练评估 failed（ADR-0039/0040/0046）、OE 成分外推 failed（ADR-0049）、对照 3 目标置换 criteria_not_met（ADR-0048）、跨背景通路 No-Go（ADR-0047）、空间锚定未锚定结果、WP8/CAR-M 的 `FAILED` 结局计数——在 HTML 中以失败色与文字双重标注，并汇总进 `negative_findings` 顶部区块。
4. 报告不 fetch 数据、不含 `<script>`、不提供任何调参或执行控件、不写回任何输入文件。
5. 森林图的 95% CI 是细胞级配对 bootstrap 产物（单次确定性实现内部离散度），页面必须逐字保留来源 artifact 的探索性边界声明，不得表述为统计重复证据。

## 7. CLI

```text
mgba evidence-report [--artifact-root artifacts] [--output DIR]
                     [--registry PATH] [--verify]
```

- 默认输出 `<artifact-root>/evidence-report/`；`--registry` 默认 `<artifact-root>/../data/registry.json`。
- 正常模式打印输出目录、manifest 路径、各区块状态与文件摘要；`--verify` 模式打印 verified 标志与差异清单，核验失败以非零退出。
- 命令不启动 Web 服务，不产生网络请求。

## 8. 源码指纹治理通道声明

新增 `src/mgba/evidence_report.py` 会改变 `package_source_digest()`（ADR-0045），进而改变新实验 manifest 的实验 ID 与 history digest。按 ADR-0045 确立的既定通道处理：`tests/test_frozen_identity.py` 的单 tick / 100 tick 实验 ID（及 100 tick history digest）常量经实测后同步更新并在 AGENTS.md §10 登记；trace digest 与 WP8 matrix 身份不含源码指纹，必须保持不变——若它们移动则视为实现缺陷，停手调查。

## 9. 验收清单

1. 九区块全部按 §2 枚举收集，缺失源降级为"未生成"且不中断；
2. `summary.json` 通过 schema 校验（`mgba-evidence-report-0.1` 必备字段、九区块顺序、证据等级枚举）；
3. 相同输入双跑全部产物字节级一致；
4. `manifest.json` 中每个生成文件的 SHA-256 与磁盘实算一致；
5. `index.html` 不含 `<script` 与 `fetch(`，含中文标签与每区块证据等级；
6. HTML 显著包含 `failed`、`criteria_not_met`、No-Go 与未锚定标注（负面结果不得被静默）；
7. `--verify` 对一致输出返回 verified=true，对被篡改输出返回差异并非零退出；
8. `tests/test_evidence_report.py` ≥8 项测试、`tests.test_reporting`、`tests.test_frozen_identity`、`tests.test_cli` 全绿。

## 10. 备选方案与回退

1. 交互式仪表板/前端框架：引入依赖与执行状态，违反零依赖与只读原则，拒绝。
2. 手工维护总览 Markdown：无法证明与 artifact 一致，拒绝。
3. 直接复用 WP9 报告页面拼贴：各产物 schema 不同，拼贴无法归一化证据模型，拒绝。
4. 把归一化逻辑放进 `reporting.py`：扩大既有冻结模块职责，新模块单文件内聚更安全，拒绝。

回退：删除 `src/mgba/evidence_report.py`、`tests/test_evidence_report.py`、`cli.py` 中新命令注册、产物目录、文档条目与本 ADR；核心链与全部历史 artifact 不变。
