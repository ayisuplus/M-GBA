# ADR-0018：L2 规则参数标定——预注册确定性搜索与 holdout 泛化判定

> 状态：Accepted
> 日期：2026-08-21

## 背景

1. 项目所有主链结局在未拟合参数下均为 `FAILED`（ADR-0010 起作为负面基线保留）。WP8 已证明 L2 静态替换产生最大终点差异并转为 `RECOVERED`——**模型类内存在非 FAILED 区域**，但"在既有 L2 规则模型类内、仅靠参数标定能否达到并泛化"从未被测量。
2. 用户授权"优化算法"方向（2026-08-21），硬件约束为单台笔记本。实测 60-tick 单次运行 178 ms，纯 stdlib 确定性搜索在该预算下完全可行；Runner 性能优化门（仅当标定太慢才触发）经实测未触发。
3. AGENTS §4 禁止"为展示效果静默调参"。因此标定必须以**预注册协议**执行：目标函数、搜索空间、预算、训练/holdout 切分和判定规则在任何评估之前冻结。

## 决定

1. 新增 `mgba.calibration` 纯搜索核心（不 import runner 或层模型，目标函数由调用方注入，可用合成目标微秒级测试）：
   - `CalibrationProtocol` 冻结：搜索种子、候选数、top-k、细化步长、sweep 上限、tick 数、参数名表；全部 fail-fast。
   - 采样：候选 $k$ 的每个坐标由 $\mathrm{Random}(\mathrm{sha256}(seed\|\text{candidate}\|k)[:8])$ 独立均匀抽取（复用 ADR-0015/0017 的 sha256 派生流模式），$[0,1)^{19}$。
   - 细化：坐标下降（声明序 × 步长 0.1/0.05 × 双向），仅当改进 $>10^{-12}$ 才接受，重复点不重复评估。
   - 参考向量恒为首个评估点并进入细化种子，**训练目标上结果不可能差于参考**。
2. 预注册协议（冻结于 `scripts/calibrate_l2_cell.py` docstring 与本 ADR）：
   - 搜索空间：`CellConfig` 的 19 个标量字段（`L2_SCALAR_PARAMETERS`，声明序）；`model_version` 与 `secretion_multipliers` 冻结于参考值。
   - 目标：训练场景（`configs/multiscale_demo.json`）60-tick 运行的 `PhenotypeWindow.mean_homeostasis`；结局类别只报告、不进入标量目标。
   - 预算：512 候选 + top-3 细化（最多 4 sweep）。
   - Holdout：`data/synthetic-feedback` 四档压力场景（calm/injury/severe/collapse），同一确定性链、同一 horizon，参考与标定配置各跑一次。
   - 判定规则（先验固定）：四档 mean homeostasis 差值全正 → `generalized`；全非正 → `not-generalized`；否则 `mixed`。
3. 冻结参考 `configs/layers/l2_reference_cell.json` 不被修改；标定向量只写入 artifact 目录（`calibrated_l2_cell.json` + 完整溯源），是否提升为版本化配置由用户决定。
4. artifact：`manifest.json` + `summary.json`（含全部 1003 条评估日志）+ `holdout.json` + `holdout.csv`，全部 write-once。

## 结果（2026-08-21 实测，search_digest `99ce6e355b8e0afa…`）

- 训练：mean homeostasis 0.2076 → 0.5927（+0.385），1003 次评估，178 s。
- Holdout：四档全部提升，平均 +0.2207，判定 `generalized`：
  - calm 0.2093→0.5984、injury 0.1847→0.5877，结局 `failed → stable`；
  - severe 0.1498→0.2034、collapse 0.1484→0.1852，结局仍 `failed`，但终末活力脱离 0（0.095/0.066）。
- 参数解读（参考 → 标定）：`repair_recovery_rate` 0.2→1.0、`stress_environment_weight` 0.7→1.0、`signal_activation_weight` 0.7→0.0、`death_effector_weight` 0.6→0.14。**多个坐标顶到 $[0,1]$ 盒子边缘**，提示最优点可能在盒外；扩大盒子属另一轮预注册协议，本 ADR 不追索。

## 科学边界

- 这是 reference model 内的参数搜索证据（AGENTS §4 第 2 级 `reference model` 诊断）：证明的是"L2 规则参数类存在使该确定性链达到 `stable` 并跨压力档泛化的点"，**不是**生物拟合、不是临床相关性、不是对真实系统的标定。
- holdout 是四个合成压力场景（同一模型类、同一链），不是独立数据模态；泛化结论限于模型类内部。
- 标定配置默认不进入任何冻结实验协议；`v0.1.0`/`0.2.0` 身份与 WP8/E3/E4/E5 矩阵位级不变（测试门禁固定）。

## 回退

删除 `calibration.py`、`scripts/calibrate_l2_cell.py`、`tests/test_calibration.py` 与文档条目即可回到 ADR-0017 状态；标定 artifact 在 git 忽略的 `artifacts/` 下，不影响任何冻结协议。
