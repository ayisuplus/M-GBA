# ADR-0030：比赛版跨尺度虚拟实验室

- 状态：已接受、实现并发布预计算版本
- 日期：2026-08-22
- 影响范围：生成链外实验调度、观察、分享与部署基础设施
- 不影响：L0–L4 DTO/Protocol、层模型、时钟、冻结实验和科学主张
- 公开入口：`https://mgba-cross-scale-lab.zluo66977.chatgpt.site`

## 1. 背景

`mgba demo-export` 已能生成自包含 CAR-M 研究观察台，但比赛评委需要一个无需安装、三分钟内可完成“选实验→设受限干预→运行或回放→检查 L0–L4→比较 L4→分享结果”的公开入口。该入口必须放大现有跨尺度证据，而不能把 UI 变成新的模型热路径，也不能为了展示效果修改负面基线或把显示投影称为真实空间。

## 2. 决策

在独立 `web/` 目录建立 Cloudflare/Sites 兼容的 React/TypeScript 网站，以“通用五层平台＋CAR-M 旗舰案例”为叙事。网站包含：

- `/`：项目问题、五层架构、CAR-M 旗舰案例和实验室入口；
- `/lab`：baseline/intervention 同 tick 双轨画布、三通道场切换、Cell 检查器、传播时间轴、L4 曲线和审计身份；
- `/runs/:id`：R2 中 30 天可分享的结果；
- `/evidence`：模型身份、科学边界、复现命令和数据来源。

首页只读取小型 catalog；完整 bundle 在选择实验后按需加载。移动端保证结果阅读与基础回放，不承诺完整编辑体验。`mgba demo-export` 的自包含 HTML 继续作为独立离线兜底。

## 3. 数据契约

`mgba.lab` 定义三个生成链外契约：

1. `LabExperimentRequest`：只允许固定 CAR-M 场景、固定目标角色/基因/seed/ticks，以及 `dose ∈ {0.0,0.7,1.0}`、`onset ∈ {early,late}`、`exposure ∈ {short,long}`；未知字段 fail-closed。
2. `LabRunBundle`：保存 baseline 与 comparison 的完整显示 trace、五层逐 Cell 状态、L3 显示坐标/场、L4 曲线、事件审计、experiment/history digest、配置摘要和科学边界。
3. catalog/file manifest：catalog 只保存实验摘要与 bundle 路径；每个 JSON 使用稳定排序和紧凑编码，文件 manifest 固定 SHA-256。

`mgba lab-export` 从现有 dose playbook、ADR-0029 raw runs 和 ADR-0023 spatial raw runs 构建三套比赛 bundle。它不运行搜索、不修改输入 artifact。独立重建已证明五个输出文件逐字节一致。

## 4. 在线边界

浏览器只调用同源 Worker：

- `POST /api/experiments` 对 request 做同构严格校验，由规范化请求、执行修订和模型配置生成确定性 `lab-run-<16 hex>`；
- 同一 run ID 优先读取 R2；新结果保存 30 天；
- `GET /api/experiments/{id}` 对不存在返回 404，对过期返回 410；
- live runner 默认关闭。关闭、超时或后端失败返回错误与 fallback bundle ID，浏览器必须明确显示“冻结预计算回放”。

Worker 不向浏览器暴露 `MGBA_RUNNER_TOKEN`。Python 服务只接受 bearer 服务凭证，限制请求体 2 KiB、每客户端每小时 5 次、全局并发 2、单次等待 45 秒，并只调用 `run_lab_experiment`。用户不能提交文件路径、目标 Cell 列表、模型名、任意配置或代码。后端以 `services/lab-api/Dockerfile` 交付，厂商由部署时的 `MGBA_RUNNER_BASE_URL` 决定。

## 5. 层级与科学边界

该能力属于跨层基础设施中的观察/实验层，不属于 L0–L4 任一层。预计算导出器读取正式 artifact；在线服务使用既有 ADR-0029 runner；UI 与 Worker 均不进入 tick。所有页面持续显示 `contract demonstrator` / `reference model` 边界、seed、model/history digest，并明确：

- 终点距离与方向不是疗效判断；
- 画布投影不是物理组织重建；
- CAR-M profile 是代理标签聚合，不是临床真值；
- 真实空间 Target 尚未生成，合成 fixture 不作外部验证。

因此该 ADR 不升级论文主张，不增加临床、数字生命或已验证涌现声明。

## 6. 保留基线与回退

- 保留 `ReferenceCrossScaleRunner`、现有层模型与全部冻结身份测试；
- 保留 `mgba demo-export` 和其字节确定性测试；
- `LAB_LIVE_RUNS_ENABLED=false` 是首发状态，三套预计算实验可独立完成比赛演示；
- 移除网站或在线服务不会破坏核心包、CLI、artifact 或实验协议；
- 后端不可用时不生成伪结果，只返回明确错误并由前端选择冻结 bundle。

## 7. 替代方案

- 直接把 Python/WASM 模型放进浏览器：拒绝。会扩大依赖、难以复用现有 runner，并模糊模型与显示层边界。
- 第一版开放任意参数和文件上传：拒绝。无法 fail-closed，增加资源与科学解释风险。
- 只部署静态单文件 HTML：保留为兜底，但不足以提供实验库、路由、分享和后续受限在线运行。
- 将完整 15-run 矩阵作为一次在线请求：拒绝。比赛交互只需一对 baseline/intervention，完整矩阵继续离线预计算。

## 8. 验证

- 309 项 Python 测试通过，其中 11 项覆盖 request、schedule、pre-onset 零差异、run/bundle digest、字节重建、鉴权和 fail-closed HTTP 边界；
- 10 项前端测试覆盖跨语言 run ID、未知字段、tick/Cell/场/L4 同步、禁用后端 fallback、404/410 与事件视界 Web Component 契约/落地页回归；
- `npm run lint`、`npm run build`、根页面及三个主要路由 smoke 通过；生产依赖审计为 0 漏洞；
- `mgba run --config configs/multiscale_demo.json` 与 `mgba sten-smoke --config configs/demo.json` 通过；
- 三套 bundle 的独立重建 SHA-256 完全一致，冻结负面基线与原离线 HTML 均未改变。
- 首发部署保持 `LAB_LIVE_RUNS_ENABLED=false`；公网首页、`/lab`、`/evidence` 与 catalog 均返回 200，在线 POST 返回显式 503 fallback，缺失分享 ID 返回 404。
