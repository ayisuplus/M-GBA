# ADR-0047：跨细胞背景的通路扰动外推契约

- 状态：20 折开发评估已完成并触发预注册 No-Go；Arc H1 保持封存（2026-09-03）
- 日期：2026-09-03
- 影响范围：生成链外数据构建、训练、OOD 评估与论文 Go/No-Go
- 不影响：现有 L0–L4 接口、冻结历史实验、核心零依赖与 MSigDB 本地使用约束

## 1. 决策

把科研主线从随机 unit holdout 改为可证伪的问题：给定扰动基因及未处理细胞背景，预测未见基因在未见细胞背景中的 50 维 Hallmark 通路响应。论文只主张“跨细胞背景的可解释扰动响应预测”，不主张完整 virtual cell、CAR-M 疗效或高层生物表型预测。

开发背景固定为 `replogle-k562`、`replogle-rpe1`、`nadig-hepg2`、`nadig-jurkat`。Arc H1 hESC 是一次性外部测试：开发阶段只可用其未处理对照构造背景输入，扰动标签保持封存。Norman CRISPRa 仅可另作域外压力测试，不混入 CRISPRi 主结果。

四个开发背景已生成真实 bundle 并通过数据门：K562/RPE1/HepG2/Jurkat 的可靠性分别为 0.494/0.765/0.723/0.534；四背景共有 577 个合格扰动基因，其中 559 个存在于冻结 Geneformer 表。20 折低秩交互模型已完成开发评估并在简单基线门上失败；Arc H1 扰动标签和三个学习型基线未进入本地开发流程，不生成论文 Go 主张。

## 2. 数据与目标

- 原始 h5ad 仅由 `.venv-train` 中的 `scripts/build_context_pathway_bundle.py` 读取；核心包不引入 NumPy、PyTorch、Scanpy 或 AnnData。
- 逐细胞按全转录组 library size 缩放至 1e4，再做 `log2(1+x)`；每条通路取集合内覆盖基因的无权均值；目标是扰动细胞均值减同背景匹配对照均值。
- 每个 gene-context 至少 50 个细胞；最终 split 总体须同时满足四背景共有且冻结 Geneformer embedding 可用，并且至少 500 个。当前从 577 个四背景共有基因中按该规则确定 559 个可建模基因；18 个未映射旧符号作为固定排除项登记，不插补。
- 每背景用固定种子 `20260903` 做 20 次细胞半分重采样：分别拆分扰动与对照细胞，重算两半的 50 维效应并取 Spearman；先对每个扰动取中位数，再对背景取中位数。任一背景低于 0.30 即 No-Go；种子随 bundle 保存并由核心门禁核验。
- `mgba-perturbation-context-bundle-0.1` 保存来源路径、SHA-256、字节数、许可、Rights、Hallmark 身份、对照状态、目标、细胞数与可靠性。

## 3. OOD 划分

`mgba ood-split-build` 只接受四个固定背景、来源可核验的 bundle 和冻结的 `mgba-gene-embedding-table-0.1`。manifest 同时登记 embedding SHA-256、四背景原始交集和未映射排除项；训练器与评估器拒绝换表。合格共享基因按 `SHA-256(salt|gene)` 排序，使用五个预注册 salt 固定拆为 70% train、15% validation、15% test；当前 559 个基因对应每折 391/83/85，外层 leave-one-cell-context-out，共 20 折。

每折要求：测试基因不出现在任何训练背景的训练标签中；outer context 的任何扰动标签不进入训练或调参。Arc H1 标签摘要随 manifest 登记且状态必须为 `sealed`。

实际 split 为 `ood-split-7118cfcf9ffda6eb`。外部来源预先固定为公共镜像 `cyrilzakka/arc-institute-virtual-cell-dataset@952b34cd3b0698a9846e9d444938e0805e76df56` 的 `adata_Training.h5ad`，SHA-256 为 `c1e1e44e4c794527984a58366c9a78506c5b20a08a6e8bce79e994f6b73a5d7e`；文件尚未下载，标签状态仍为 sealed。该镜像只作为 Arc 生成数据的固定传输来源，不声称与当前官方 GCS 对象字节一致。

计划中的“context perturbed mean”不能用于联合 OOD，因为它需要查看 held-out context 的扰动标签。实现因此固定为：

- `training_perturbed_mean`：所有场景可用；
- `gene_mean`：仅 context-OOD 可用；
- `context_perturbed_mean`：仅 gene-OOD 可用；
- joint-OOD 不接受后两者，评估器发现多余或缺失预测即拒绝。

## 4. 模型与基线

扰动输入是冻结的 768 维 Geneformer 基因嵌入，PCA 仅在外层训练基因上拟合至 64 维。背景输入是该背景未处理对照的 50 维 Hallmark 状态，按训练背景统计量标准化。目标按训练 gene-context 对统计量标准化。

主模型固定为：

```text
y = b + A·p + B·c + D[tanh(Pp) ⊙ tanh(Cc)]
```

交互秩 `{8,16,32}`、学习率 `{1e-4,3e-4,1e-3}`、weight decay `{1e-5,1e-4,1e-3}`；最大 1000 epochs、patience 50。超参只通过内层 leave-one-training-context-out 选择；最终五个固定 seed `17,42,73,101,211` 的预测取均值。每个 seed 的权重、PCA 与标准化统计保存为 `.npz` 并登记 SHA-256。

简单基线固定为 zero response、training perturbed mean、可用场景中的 gene/context mean、gene-only ridge、context-only ridge、gene+context additive ridge；ridge alpha 固定为 1.0。GEARS、scGPT、biolord 必须由官方实现独立运行并先从全表达预测按同一无权 log2FC 均值映射到 Hallmark 空间；导入件强制记录官方仓库、完整 Git commit、版本、Hallmark digest 与逐折制品 SHA-256。三者必须全部存在才可把 prediction artifact 标为 `complete`。官方实现身份跨折相同，逐折预测文件摘要允许且必须各自记录。

首次20折简单基线筛查覆盖 1,700 个 joint-OOD 单元，未使用 outer-context 扰动或 test-gene 训练标签。联合 OOD 标准化 macro-MAE 为：gene-only ridge 0.75420、additive ridge 0.75976、zero response 0.76135、training perturbed mean 0.76940、context-only ridge 0.77068；因此后续主模型相对简单基线的 5% 门对应不高于约 0.71649，且仍须满足 bootstrap 与逐背景门。

首次 20 折低秩交互模型开发结果覆盖相同的 1,700 个 joint-OOD 单元，标准化 macro-MAE 为 0.81214，相对最佳简单基线退化 7.68%。交互模型减去 gene-only ridge 的基因分块 bootstrap 保持原 unit 权重，平均差值为 0.05794，95% CI 为 0.04880–0.06711，表明退化而非改善。四个背景均未胜出；HepG2/Jurkat/K562/RPE1 相对各自冻结简单基线分别退化 10.37%/7.08%/28.66%/7.00%。这些条件均为开发 Go 的必要条件，因此即使补齐学习型基线也不能改变本轮主模型的 No-Go；按预注册规则停止后续学习型基线和外部测试，保留负结果。开发 evaluation 为 `context-pathway-eval-f85593e931801a3d`。

## 5. 评估与门禁

主模型运行前冻结报告结构：Figure 1 仅展示数据流、四背景外层划分和封存边界；Figure 2 展示 joint-OOD 标准化 macro-MAE 及基因分块 bootstrap 95% CI；Figure 3 展示四背景相对各自最佳简单基线的改善；Figure 4 展示四项消融；外部 H1 只在开发门通过后加入 Figure 5。Table 1 固定报告细胞数、扰动数、共有/排除基因和 split-half 可靠性；Table 2 固定报告主次指标与 BH 校正结果。不得依据主模型结果更换指标、坐标尺度或隐藏失败背景。

`mgba context-pathway-evaluate` 从 bundle 重取真值和训练统计量，拒绝 split/source digest 不匹配、场景覆盖泄漏、基线无法重算、协议或超参漂移、学习型基线不完整。产物为 `mgba-context-pathway-predictions-0.1` 与 `mgba-context-pathway-evaluation-0.1`，均 write-once。

主指标是训练折标准化后的 50 通路 macro-MAE；次指标为逐通路跨扰动 Spearman 的宏平均、方向一致率和强响应 top-5 recall。主指标差异按扰动基因分块 bootstrap 10,000 次并报告 95% CI；次指标使用同一基因分块（Spearman 使用固定全样本 pathway rank contribution）并把全部比较 p 值作为一个 Benjamini–Hochberg family 校正。

开发 Go 同时要求：joint-OOD 相对最佳简单基线改善至少 5% 且 95% CI 不跨 0；相对最佳学习型基线改善至少 2%；四个开发背景至少三个胜出；任一背景退化不超过 2%。背景胜负分别对该背景自己的最佳简单基线计算。所有 20 折与三学习型基线未齐时只能输出 `incomplete`。完整后以 20 折所选超参的众数锁定外部模型，平票按 `(rank, learning_rate, weight_decay)` 字典序裁决。

不提供 external 参数时 evaluator 的 `paper_verdict` 固定为 `sealed`。只有完整且通过的开发 evaluation 才可调用同一 CLI 的 external 模式；它在读取 Arc bundle 前以排他创建写入 `mgba-external-test-access-lock-0.1`，已存在即拒绝。外部预测文件不得携带 target，并须在标签访问前覆盖五个 salt 的全部锁定 test gene；解封后只按 Arc 实际覆盖求交评分，核验原始标签摘要，并把状态改为 `consumed`。Arc H1 相对最佳简单基线改善至少 3% 才输出 `paper_verdict: go`，否则 `no-go`。未通过时不换指标、不挑子集、不扩展 L1–L4，回到 evidence-governed 软件论文路线。

本轮 evaluation 的 `coverage.protocol_complete` 因三个学习型基线按 No-Go 停止而为 `false`，但已完成的 20 折使多个必要门确定失败，因此机器结论为 `development_verdict: failed`。`paper_verdict` 与 Arc H1 均继续保持 `sealed`。
