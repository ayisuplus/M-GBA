# ADR-0031：群体动力学观察层

- 状态：已接受并实现
- 日期：2026-08-22
- 影响范围：生成链外轨迹观察、比赛 bundle 和网站可视化
- 不影响：L0–L4 DTO/Protocol、层模型、tick 循环、checkpoint、history digest、冻结实验和 E3 分级

## 1. 背景

比赛工作台已经能逐 Cell 回放 L0→L4，但评委仍需自行从几十条细胞轨迹中判断群体何时形成共同方向、何时分化，以及这些变化与 L4 观测在时间上如何对应。用户提供的群体行为论文启发了“用低维群体状态和状态转换理解多 Agent 轨迹”的方法形状；论文中的二元 Ising/Glauber 预测模型、冷漠/共识/极化术语和机制结论不直接迁入 M-GBA。

本阶段需要先回答一个更小、可审计的问题：能否只从正式 `MultirateRun` 重算连续群体代理、冻结分类和时间关联，并把它作为可移除的观察层加入比赛网站？

## 2. 决策

新增 `mgba.collective_dynamics.CollectiveDynamicsObserver`。它只读取已完成的 run 或严格验证的序列化 raw run，不被 runner 或 L0–L4 模型导入。每个 Cell、每个 tick 的无量纲响应代理为：

```text
zᵢ(t) = activationᵢ(t) - stress_loadᵢ(t)
```

对全组织或外部 cohort 计算：

```text
direction      m(t) = mean(zᵢ)
intensity      c(t) = mean((activationᵢ² + stress_loadᵢ²) / 2)
polarization   p(t) = mean((zᵢ - m)²)
edge_alignment a(t) = mean(zsource × ztarget)
```

无 cohort 内边时 `edge_alignment=null`。同时保存 activation-dominant、stress-dominant 和 neutral Cell 比例。`z` 只表示 activation-dominant ↔ stress-dominant 参考轴，不携带疗效方向。

## 3. 冻结阈值与分类

配置 schema 为 `mgba-collective-dynamics-config-0.1`，默认文件为 `configs/experiments/collective_dynamics.json`：

| 参数 | 值 |
|---|---:|
| Cell / group direction threshold | 0.15 / 0.15 |
| low / high intensity threshold | 0.04 / 0.16 |
| population split threshold | 0.09 |
| minimum dwell | 3 ticks |
| endpoint window | 5 ticks |
| persistent / low-activity fraction | 0.50 / 0.80 |

逐 tick 状态严格按 `low_activity → activation_dominant → stress_dominant → population_split → coactivated_balance → transitional` 的优先级判定。轨迹严格按 `oscillatory → reversal → activation/stress_convergence → persistent_activation/stress → persistent_split → persistent_low_activity → indeterminate` 判定。

持续方向段必须驻留至少 3 ticks。方向切换数 0/1/2/≥3 的 Cell 分别标为 `stable`、`single_switch`、`intermittent`、`oscillatory`。短暂越界不会被提升为合格转换；没有转换时输出“未观察到合格转换”，不在观察后改阈值。

## 4. Cohort 与 L4 时间关联

`cohort_map` 是外部 `Cell id → cohort name` 映射。缺省时只分析 `all_cells`；提供时必须完整覆盖全部已知 Cell、不能增加未知 Cell，也不能使用保留名 `all_cells`。角色不进入 L1–L4 DTO。CAR-M bundle 同时输出全组织与四个角色 cohort；普通实验默认工程巨噬细胞，固定图/空间 L3 对照默认全组织。

合格群体状态转换只关联：

- 转换前最后一次 L4 观测；
- 转换时刻或之后第一次 L4 观测。

结果字段固定标记 `temporal_association_only`。baseline/intervention 比较报告首次逐 tick 状态分化、direction/intensity/polarization 平均绝对差、轨迹分类变化，以及分化后首个 L4 观测差异；这些都不是因果归因。

## 5. Artifact 与 Lab 契约

- 公共接口：`CollectiveDynamicsConfig`、`CollectiveDynamicsReport`、`analyze_collective_dynamics`、`compare_collective_dynamics`；
- CLI：`mgba collective-analyze --input RUN.json [--cohort-map cohorts.json] --output collective.json`；
- artifact schema：`mgba-collective-dynamics-0.1`，包含 observer/config/source/report digest、逐 cohort 序列、转换和个体分类；写入采用 write-once；
- `LabRunBundle` 顶层继续使用 `mgba-lab-run-bundle-0.1`，仅新增可选 `analysis.collective_dynamics` 和可选 Cell `collective_response`；旧 bundle 缺字段时前端显示兼容提示；
- 在线执行 revision 升级为 `carm-state-conditioned-paired-0.2`，请求枚举和允许字段不变，避免旧 R2 run ID 指向不同内容。

三套预计算 bundle 已从原 raw artifact 重导。相对移除新字段后的同 bundle，剂量/时序/空间 bundle 体积分别增长约 10.5%/9.0%/8.6%，均低于 15% 门槛。

## 6. 网站

工作台新增 direction–intensity 双轨相图，与主播放器共用 tick。颜色表示六种逐 tick 状态；用户可切换 cohort、查看轨迹类型和 Cell archetype 计数，并点击空心转换点读取 L4 前后观测及该 tick 的事件审计。页面同时显示公式、阈值、observer/config digest 和“不是物理相变或临床预测”的边界。

旧分享链接和旧 bundle 不在浏览器临时重算或猜测新指标，只显示“该结果尚无群体动力学分析”，原 L0–L4 阅读能力保持可用。移动端保留可横向阅读的相图、当前状态和折叠式摘要。

## 7. 未采用方案

- **直接拟合论文的 Ising/Glauber 模型**：拒绝。当前 Cell 是连续状态、拓扑条件不足、非重复 seed 不足，二值化会引入尚未验证的预测假设。
- **把状态或 cohort 写入 L2/L3 DTO**：拒绝。这是事后观察语义，不是生成状态。
- **用 CellAction 作为第一版响应轴**：延期。计划先冻结 activation/stress 轴，避免同时增加行为选择语义。
- **为了出现转换而按实验调阈值**：拒绝。阈值在读取结果前冻结，无转换是有效负面结果。

## 8. 回退与后续门禁

回退只需移除 `analysis.collective_dynamics`、Cell 的可选显示字段、相图组件、CLI 和本模块；raw run、LabRunBundle 顶层 schema、runner 与全部层模型不受影响。`mgba demo-export` 的离线契约不改变。

统计力学预测 surrogate、参数拟合或自动拓扑优化须另立 ADR，并至少满足：两个拓扑条件、五个非重复 seed、冻结阈值和正式基线对照。当前结果只能称“群体动力学”“状态转换”和“reference proxy”，不升级 E3 `emergence_candidate` 阶梯。

## 9. 验证

- 公式、阈值相等边界、分类优先级、驻留时间、反转/振荡、单 Cell、无边、全中性、短轨迹、非有限值和身份漂移均有自动测试；
- cohort 覆盖 fail-closed，且总 polarization 与加权组内/组间方差分解一致；
- 相同 raw run 的 report/digest/write-once 文件一致，相同 report 对比全零；
- CAR-M late onset 前 30 ticks 的全部 cohort 序列逐字段相同；
- Observer 前后 `MultirateRun.as_dict()`、checkpoint 和 history digest 不变；
- 网站覆盖有/无新字段、cohort、tick、转换点、L4 关联、事件审计和科学边界；live runner 继续默认关闭。
