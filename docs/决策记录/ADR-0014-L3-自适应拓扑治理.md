# ADR-0014：L3 自适应拓扑治理与 E5 静态/动态对照

> 状态：Accepted
> 日期：2026-08-20

## 背景

1. MVP 计划的 E5 实验自冻结以来一直停留在纸面："在五层闭环稳定后，比较静态邻域、规则 rewiring 和 STEN 语义拓扑；指标同时包含宏观表型、通信成本、拓扑稳定性和多样性"。ADR-0005 的备选方案 3 明确写道"STEN 动态 rewiring 应在固定图 reference model 稳定后作为 E5 对照"——固定图参考模型已稳定（v0.1.0 冻结 + 反馈/策略扩展均不触碰默认拓扑），准入条件满足。
2. 核心原则 §3 L3 规定："Agent 只能提出拓扑意图；系统约束负责授权与提交"。STEN 子系统（`sten.py`）已有 `TopologyProposal` 提案与 `DirectedTopology` 受保护变更的先例，但从未进入五层主运行链。
3. 2024–2026 前沿调研（检索时间 2026-08-20）：
   - **自适应/共演化网络**：Gross & Blasius 的 adaptive network 范式（节点按邻居状态重连边以规避"感染/应激"源）在 2023–2025 的共演化网络研究中持续扩展（Min et al., *Threshold Cascade Dynamics in Coevolving Networks*, PMC 2023）；其核心机制是"应激回避重连"。
   - **顶点模型 T1 转换**：上皮组织中的邻居交换（T1 transition）是组织拓扑重排的标准机制（Lange et al., *Vertex models capturing subcellular scales*, PMC 2025；*Geometry of T1 transitions in epithelia*, arXiv:2504.16765, 2025）：一条边收缩消失、一条新边生成，边数守恒、局部性、不可逆。
   - **多智能体拓扑自适应**：MANTA（arXiv:2607.28527, 2026）提出推理期通信拓扑自演化：agent 提出结构变更、框架层裁决；SO-MAS 综述同样强调局部规则产生可扩展的自组织。
   - PhysiCell/PhysiBoSS 仍使用固定或力学驱动邻域，没有显式治理层；这正是本项目的差异化空间（治理可审计）。
4. 结论：融合三个优势——T1 式边交换的守恒拓扑类、应激回避重连的自适应规则、提案→授权→提交的治理链——实现确定性 `DynamicTopologyTissueModel`，作为 E5 的动态对照条件。

## 决定

1. 新增 `mgba.layers.l3_adaptive.DynamicTopologyTissueModel`，实现既有 `TissueModel` 协议（含 ADR-0012 的 `constraint` 入口，可组合使用）。`StaticTissueModel`、`TissueEnvironmentModel`、`ConstraintAwareTissueModel` 与 CAR-M 适配器全部不修改；`_validated_inputs` 增加 `dynamic_topology=False` 旗标，默认行为位级不变。
2. **拓扑意图（提案）**：每个节点 $i$ 从局部信息生成至多一个交换提案——候选丢弃边取其入边中应激最高者，候选新增边取全场分泌最强且未连入者；不使用任何全局 L4 指标。
3. **系统约束（授权）**：提案必须通过治理检查——无自环、无重复边、端点存活（非 DEAD）、新源出度不超 $\Delta_{\max}$、交换增益不低于边际阈值 $\theta$；按 cell id 排序确定性处理。
4. **提交与预算**：每节点每 tick 至多一次交换；全局每 tick 至多 $B$ 次；所有被接受的交换同步应用到下一拓扑，并写入新 `TissueState.metadata.source` 哈希链留痕（含丢弃/新增端点与得分）。
5. 拓扑状态寄宿在 `TissueState.edges`：`step` 的 `edges` 参数语义为"种子拓扑"（首 tick）；后续 tick 以 `previous_state.edges` 为准。checkpoint 因此自动精确恢复，schema 不变。
6. 新增 `mgba topology-experiment` CLI 与 `mgba.topology_experiments`：同场景同种子配对运行 `static_topology`（参考 L3）与 `adaptive_topology`（动态 L3）两个 runner，复用 WP8 配对比较指标；构造器强制两 runner 仅 L3 版本不同。这是 E5 的"静态邻域 vs 规则 rewiring"对照实例。
7. 新增 `scripts/synthetic_topology_benchmark.py`：复用共享合成数据集运行 E5 对照并汇总 CSV/JSON（含拓扑稳定性指标：交换计数）。

## 数学原理

记 $t$ 时刻节点 $i$ 的入邻集为 $\mathcal{N}^-_i(t)$，节点应激为 $\sigma_j(t)$，动作分泌为 $s_k(t)$。

**提案评分**：

$$\text{drop}_{j\to i}(t) = \sigma_j(t), \qquad \text{add}_{k\to i}(t) = s_k(t)$$

$$j^* = \arg\max_{j \in \mathcal{N}^-_i(t)} \sigma_j(t), \qquad
k^* = \arg\max_{k \in \mathcal{C}_i(t)} s_k(t)$$

其中候选集 $\mathcal{C}_i(t) = \{\,k \neq i : k \notin \mathcal{N}^-_i(t),\ k\ \text{alive},\ \deg^+_{k}(t) < \Delta_{\max}\,\}$；并列按 cell id 字典序裁决。

**授权条件**（全部满足才提交）：

$$\mathcal{N}^-_i(t) \neq \varnothing \wedge \mathcal{C}_i(t) \neq \varnothing \wedge
\text{add}_{k^*\to i}(t) - \text{drop}_{j^*\to i}(t) \ge \theta$$

**提交**（T1 式边交换，入度守恒）：

$$E(t+1) = E(t) \setminus \{(j^*, i)\} \cup \{(k^*, i)\}$$

**预算**：节点按 id 排序处理；每节点每 tick 至多一次；全局接受数 $\le B$。

应激回避（drop 高分应激源）对应 Gross–Blasius 自适应网络的规避重连；边交换守恒对应顶点模型 T1 转换；提案→授权→提交对应 MANTA 的框架层治理。

## 结果

- E5 从纸面实验变为可执行协议：静态与动态拓扑在五层主链上的配对差异（L3 距离、L4 有向差值、传播 tick、拓扑交换计数）可追溯、可复现。
- 无动态模型注入时所有冻结基线位级不变；`_validated_inputs` 默认旗标保持"轨迹内静态拓扑"门禁。
- 动态参数未经拟合；E5 结果（无论动态拓扑改善或恶化结局）都是 reference model 内的对照证据，不构成"自组织/涌现"宣称。科学等级不变。

## 回退

删除 `mgba/layers/l3_adaptive.py`、`topology_experiments.py`、对应配置/CLI/测试/脚本与文档条目，并还原 `_validated_inputs` 的旗标参数即可回到 ADR-0013 状态；所有冻结基线不依赖本次新增代码。
