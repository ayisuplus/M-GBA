# ADR-0008：WP8 扰动、层级消融与模型内因果路径

> 状态：已接受  
> 日期：2026-08-18  
> 作用范围：WP8 E0–E2 批量实验、效应量、传播延迟与 artifact

## 背景与研究问题

WP7 已证明五层 reference model 可以持续运行、暂停和恢复，但“能跑”不等于每层都有可测贡献。默认 100 tick 轨迹走向 `FAILED`，必须通过冻结对照实验判断扰动在哪里进入、在哪一层被放大或缓冲，以及简单层替换如何改变结果。

WP8 回答：

> 在当前无量纲 reference model 内，L0 扰动和 L1–L3 层替换分别如何改变逐层状态与最终 L4 表型？

“因果”在本 ADR 中只表示同一代码模型、同一初态和同一 seed 下的受控反事实差异，不外推到真实生物机制、治疗或临床因果。

## 冻结实验矩阵

每个条件在 seed `41、42、43` 下运行 30 tick。reference model 当前是确定性的，seed 可能只改变实验身份而不改变轨迹；这种零 seed 方差必须如实保存。

### Baseline

- `baseline`：五层全部使用当前配置驱动 reference model，无 L0 钳制。

### E1：L0 修复表达剂量

目标固定为 `cell-a.repair_expression`：

| 条件 ID | 钳制值 | 解释 |
|---|---:|---|
| `repair_kd_000` | 0.0 | 完全敲低 |
| `repair_clamp_050` | 0.5 | 中间剂量硬钳制；相对自然轨迹可在不同时刻表现为敲低或过表达 |
| `repair_oe_100` | 1.0 | 过表达上界 |

钳制只由 L0 `perturbations` 入口进入。后续层不得读取条件 ID 或目标值。

### E2：层级静态替换

| 条件 ID | 替换 | 保持不变 |
|---|---|---|
| `l1_static` | `StaticMolecularModel` | L0、L2–L4、Runner、场景 |
| `l2_static` | `StaticCellModel` | L0–L1、L3–L4、Runner、场景 |
| `l3_static` | `StaticTissueModel` | L0–L2、L4、Runner、场景 |

这些条件是契约兼容的简单替换，不等于“删除生物层”。若替换不改变某个指标，该零效应是有效负结果。

## E0：完整性门禁

矩阵中的每次运行必须满足：

- 请求的每个 tick 都存在；
- 每 tick 具有 L0→L1→L2→L3 相邻转换；
- 计划 L4 tick 才具有 L3→L4 转换；
- Cell ID 跨层保持一致；
- manifest、checkpoint、历史摘要和最终窗口完整。

E0 失败时不得生成条件比较或汇总。

## 逐层效应量

同一 seed 下，条件终点与 baseline 终点先转换为归一化数值向量，再计算平均绝对差：

```text
layer_effect(Lk)
  = mean(abs(condition_vector(Lk) - baseline_vector(Lk)))
```

向量定义在批量实验前冻结：

- L0：每 Cell 的 6 个 `TranscriptState` 表达值；
- L1：每 Cell 的 6 个 `MolecularState` 值；
- L2：每 Cell 的 phase 不同指示值、activation、viability、stress_load；
- L3：边集合不同指示值、每节点 stress/resource/signal，以及 9 个组织聚合指标；
- L4：vitality、damage_burden、inflammation、homeostasis、recovery_capacity。

所有距离位于 `[0,1]`。它是 reference 状态空间中的描述性效应量，不是标准化真实世界 effect size。

同时保存五个有方向的终点 L4 差值：

```text
metric_effect = condition_final - baseline_final
```

例如 vitality 为负表示条件终点活力低于配对基线。

## 传播延迟

对 L0–L3，从 tick 1 开始寻找逐层距离第一次严格大于 `1e-12` 的逻辑时间。L4 只比较计划观测；若计划观测均未变化但终点只读观察发生变化，则记录终点 tick。

未发生差异时保存 `null`，不能写成 0。由于一个快速 tick 内按 L0→L1→L2→L3 同步顺序上行，多层可能具有相同逻辑 tick；跨层事件顺序仍由 trace 明确区分。

## 多 seed 汇总

每个非 baseline 条件保存三个与同 seed baseline 配对的 `CausalComparison`，再计算：

- 每层平均绝对效应；
- 每个 L4 指标的平均有向差值；
- 每层非空首次差异 tick 的均值；
- 四类 `OrganismOutcome` 计数；
- 所有 baseline/condition 实验 ID 与历史摘要。

WP8 不进行 p 值或置信区间推断。只有三个 seed 且模型无随机动力学时，伪造显著性没有意义；WP9 再在引入合理随机源和更多重复后升级统计协议。

## Artifact

矩阵 ID 由矩阵配置、场景和各 Runner 模型版本的规范化摘要产生。目录冻结为：

```text
<artifact-root>/<matrix-id>/
├── manifest.json
├── raw/
│   ├── baseline/seed-41.json
│   ├── repair_kd_000/seed-41.json
│   └── ...
└── derived/
    └── summary.json
```

`raw/` 保存完整 `MultirateRun`，不得由分析代码修改；`derived/summary.json` 可从 raw 重建。冲突路径不得静默覆盖。条件 ID 只能使用小写字母、数字、下划线和连字符，防止 artifact 路径漂移。

## 验收与失败判据

1. 完整 reference 矩阵包含 7 个条件 × 3 个 seed = 21 次运行，每次 30 tick；
2. 同一配置重复运行得到完全相同的矩阵 ID、比较和摘要；
3. `repair_kd_000` 的差异必须从 L0 正式入口出现并沿 L1→L2→L3 到达终点 L4；
4. L1/L2/L3 静态替换条件只能更换目标层模型版本，其他层版本和场景配置保持不变；
5. 每个比较可追溯到 baseline 与 condition 的实验 ID、seed 和历史摘要；
6. 零效应、`null` 传播时间、相同 seed 轨迹和失败结局均不得被过滤；
7. 配置缺字段、重复 seed/条件、越界剂量、未知消融、非法条件 ID 或少于两个 seed 必须失败；
8. raw/derived artifact 为纯 JSON，冲突写入必须失败；
9. 完整单元测试、`mgba experiment`、单 tick、多速率和 STEN smoke 门禁全部通过。

## 备选方案

1. 只比较最终 L4：无法判断差异在哪层出现，拒绝。
2. 用不同 seed 的条件与 baseline 直接比较：混入初态差异，拒绝；采用同 seed 配对。
3. 删除某一层：破坏五层核心，拒绝；使用契约兼容静态替换。
4. 立即使用 Cohen's d/p 值：当前确定性重复没有有效方差模型，推迟。
5. 只保存汇总表：无法复核路径，拒绝；完整 raw trace 必须保留。

## 影响、局限与回退

- WP8 增加实验编排和观察代码，不改变五层运行状态或层模型公式。
- 逐层距离依赖当前 DTO 字段；字段版本变化时必须发布新矩阵协议，不能把不同向量定义混为一组。
- 静态替换可能同时改变多个下游量，不能据此声称真实生物层的独立作用。
- 若实验代码有误，可从 21 个原始 run artifact 重建；层模型和 WP7 Runner 不需要回退。
