# ADR-0022：CAR-M 跨尺度研究观察台——旧项目交互资产的只读迁移

> 状态：Accepted  
> 日期：2026-08-21

## 背景

用户要求以“CAR-M 肿瘤 + 研究观察台 + 比赛/答辩”为下一阶段目标，并提供旧项目 `D:\car-m-virtual-cell` 作为参考。旧项目包含浏览器 ABM、二维 Canvas、十通道场、实验保存/比较、TCGA/GAT 推理和大量展示资产；当前仓库已有 `mgba demo-export`，但只能在单画布中切换条件，缺少同 tick 反事实对照和正式事件审计。

旧 ABM 的 24 维节点特征和 GAT 预测会直接进入细胞行为热路径，且空间位置/连续场没有对应的正式 checkpoint DTO。直接移植会同时改变 L2/L3、引入隐藏状态，并让旧 GAT 绕开当前相邻层协议，因此本 ADR 不迁移旧动力学，只迁移观察交互模式。

## 新能力准入

1. **归属**：核心模型之外的只读跨层观察基础设施。
2. **增强对象**：升级既有 `demo-export`；不替换任何 L0–L4 基线。
3. **问题**：让相同 seed/tick 的 baseline 与 CAR 干预能够并排比较，并把宏观差异追溯到单细胞 L0→L1→L2→局部 L3。
4. **判据**：显示值与冻结 raw run 逐项和解；输出字节级确定；页面自包含；高剂量负面基线原样保留。
5. **可移除性**：观察台可独立回退，runner、DTO、配置和实验矩阵不受影响。
6. **可解释性**：场热图明确标记为固定布局节点值的径向显示投影，不冒充连续物理场或真实空间坐标。

## 决定

1. 将 playbook 升级为 `mgba-demo-playbook-0.2`，增加每条件冻结结局、逐 tick L0/L4 调度和相邻转换审计、观察层语义与旧项目交互来源说明；raw run 仍是唯一事实源。
2. HTML 观察台使用同步双画布：左侧固定 baseline，右侧选择 CAR 关闭/标准剂量/最大剂量；时间轴、播放速度和细胞选择在两轨共享。
3. L3 显示层可切换压力、信号、资源径向投影；投影只读取每 tick `TissueNodeState` 与确定性 role-ring 布局，从不回写模型。
4. L4 曲线、L3 当前状态、L4 终末值和单细胞 L0/L1/L2/局部 L3 均报告 baseline、干预和有向差值；差值不自动解释为改善。
5. 页面保留 experiment ID、history digest、playbook digest、seed、层路径、扰动事件数和科学边界，继续作为零网络依赖的单文件交付物。

## 科学边界

- 这是展示与可审计性深化，不是空间 L3 模型；细胞不会移动，热图不参与动力学。
- 旧项目的连续细胞因子场、迁移、增殖、吞噬和 GAT 不进入当前生成热路径。
- 真正空间 L3 需要单独 ADR：正式空间 DTO、checkpoint 恢复、空间邻域对照和跨尺度指标必须同时定义，不能以 UI 动画替代。
- CAR-M profile 和所有 L4 值仍是代理/reference 指标，不是临床预测。

## 验证与回退

- `tests/test_demo_export.py` 校验新 schema、观察语义、审计字段、双画布、场开关、自包含性、raw 对账和负面基线。
- `mgba demo-export --output-dir artifacts/demo-observatory` 生成实际观察台供浏览器验收。
- 回退本 ADR、`demo.py` 的 playbook/HTML 变更和对应测试即可；没有核心状态或配置迁移。
