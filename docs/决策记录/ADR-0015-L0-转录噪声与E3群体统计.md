# ADR-0015：L0 种子化转录噪声与 E3 群体统计判据

> 状态：Accepted
> 日期：2026-08-20

## 背景

1. MVP 计划 W14/M9（E3 微观规则到宏观模式）与 AGENTS §10 均记录："三个 seed 的轨迹效应完全相同，因为 reference model 没有随机动力学；当前不做显著性推断"。E3 的准入条件是多种子统计——而多种子统计在无随机源时退化为重复计算，协议无法执行。
2. 核心原则 §5 最小科学证据第 4 条："相同微观配置和种子能够复现实验；不同种子形成可统计的分布"。这要求随机性存在且**显式种子化**（AGENTS §6：所有随机性来自显式种子，配置、模型版本和代码版本进入 manifest）。
3. 2024–2026 前沿调研（检索时间 2026-08-20）：
   - **爆发式转录的 telegraph 模型**：*Principles of bursty mRNA expression and irreversibility in single cells*, arXiv:2405.12897（2024）给出开关式转录的稳态分布；Sukys et al. 2025（PMC12000877）确认 burst frequency/size 两参数刻画。
   - **噪声驱动的命运决策**：Nature Index 综述（2025）总结随机基因表达噪声影响细胞命运决策、应激响应与 bet-hedging；单细胞机制推断综述 arXiv:2505.11460（2025）确认噪声参数可辨识性。
   - 结论：完整 telegraph 过程需要 Gillespie 级采样且改变 L0 时间语义，超出"一次只升级一层、保持契约"的约束；采用其**一阶矩近似**——对确定性泄漏更新叠加有界乘性噪声，保留 L0 的同步时钟与 `TranscriptState` 契约。
4. 涌现判据沿用 AGENTS §4 的五级术语与核心原则 §3.3"涌现只用于未被直接编码、跨种子稳定出现的宏观模式"；统计方法采用无分布假设的描述量（均值/标准差/变异系数）+ 预注册阈值分级，不引入 p 值宣称。

## 决定

1. 新增 `mgba.layers.l0.NoisyDiscreteGrnModel`（`DiscreteGrnModel` 子类）：确定性右端与父类逐位相同，仅在扰动前对每个基因值叠加有界乘性噪声。随机源为每 (cell, L0 更新时刻) 派生的确定性 RNG：

   $$\text{rng}_{c,t} = \mathrm{Random}\bigl(\mathrm{sha256}(\text{seed}\|c\|t)\bigr)$$

   噪声注入采用 telegraph 噪声的一阶矩近似（乘性均匀抖动）：

   $$x_i' = \mathrm{clamp}\bigl(x_i\,(1 + \sigma_\eta\,u_i),\ 0,\ 1\bigr),\qquad u_i \sim \mathcal{U}[-1, 1]$$

   $\sigma_\eta$ 为冻结配置 `noise_sigma`。该派生只依赖 scenario seed、cell id 与 L0 状态时间，**不需要扩展 `GenomeModel` 协议**，checkpoint 恢复后自动复现（RNG 无状态，逐调用重建）。
2. `DiscreteGrnModel` 与 `StaticGenomeModel` 不做任何修改；噪声模型仅通过 runner 注入使用，默认链位级不变。
3. 新增 `mgba.e3_statistics`：E3 多 seed 群体统计层。
   - 宏观模式量取每 run 终点 L3/L4 的五个标量（`dead_fraction`、`mean_viability`、`tissue_damage`、`homeostasis`、`inflammation`）；
   - **稳定性**：变异系数 $\mathrm{CV} = \sigma/\mu$（$\mu$ 接近零时用绝对标准差）；
   - **编码独立性**：宏观量与"微观驱动线性预测"的残差比例 $R^2$ 补数，即 $1-R^2$（微观驱动取 L0 损伤响应与信号表达的种子内均值）；
   - **持续性**：模式超过预注册阈值的 seed 比例；
   - 分级：`aggregation`（$\mathrm{CV}$ 高于阈值，噪声主导）/ `group_dynamics`（稳定但与微观驱动强耦合）/ `emergence_candidate`（稳定、弱耦合、持续），阈值全部预注册在配置中。
4. 新增 `mgba e3-experiment` CLI：同场景多种子运行噪声 L0 链（可选对照：确定性 L0），输出 E3 分级与描述统计 artifact。
5. 新增 `scripts/synthetic_e3_benchmark.py`：复用共享合成数据集，多种子运行 E3 并汇总分级结果 CSV/JSON。

## 结果

- E3 协议第一次可执行：不同 seed 形成真实分布，核心原则 §5 第 4 条的"可统计分布"从纸面变为可测量。
- 显式种子化满足 AGENTS §6 随机性约束；RNG 派生进入 L0 source digest 哈希链，轨迹可审计。
- 噪声幅度与 E3 阈值均未拟合；E3 分级结果（无论 aggregation 还是 emergence_candidate）都是 reference model 内的诊断输出，不构成已验证涌现宣称（AGENTS §4：validated result 需要冻结协议、统计与消融，本实现只到 emergence candidate 判据的计算）。

## 回退

删除 `NoisyDiscreteGrnModel`、`e3_statistics.py`、对应配置/CLI/测试/脚本与文档条目即可回到 ADR-0014 状态；确定性 L0 与所有冻结基线不依赖本次新增代码。
