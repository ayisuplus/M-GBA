# ADR-0035：解除本机不训练前提与 L0 扰动响应训练轨道

- 状态：前提修订已接受（项目所有者 2026-08-28 明确授权）；L0 训练管线按本文边界实施
- 日期：2026-08-28
- 影响范围：训练基础设施（独立环境）、AIVC Stage 1–3 下载授权、首个训练目标 L0 层内替换
- 不影响：核心包零依赖身份、五层 DTO/Protocol、`ReferenceCrossScaleRunner`、全部冻结基线与冻结矩阵、比赛站

## 1. 背景与前提变更

`data/aivc/README.md` 写有"本机约束：不训练任何模型"与"不下载任何以训练为目的的资源"。该约束是 GPU 未就位时期的**阶段决策**；`docs/计划文件/可行性评估.md` §3.3 早已核验本机 RTX 5090 32607 MiB + PyTorch 2.7.0+cu128 + CUDA 可用并明确"硬件有充分余量"。2026-08-28 项目所有者确认硬件到位（32 GB 显存 / 192 GB 内存）并授权开始"接入真实数据 + 训练"升级，本 ADR 正式解除该阶段约束并冻结训练边界。

## 2. 准入六问（AGENTS.md §2）

1. **属于哪层**：训练环境是跨层基础设施；首个训练目标是 **L0 层内替换**（训练版六节点 GRN/MLP 变体）。
2. **替换/增强哪个基线**：替换对象为 ADR-0017 的冻结权重 `NeuralGrnModel` 契约演示器；确定性 `DiscreteGrnModel` 与全部参考模型**永久保留为默认与基线**，训练变体只在显式单层替换实验中出现。
3. **研究问题**：真实 Perturb-seq 扰动响应经冻结的 Hallmark 六节点语义桥（`data/aivc/README.md`）聚合后，能否方向性地锚定 L0 扰动语义（对照 E1 扰动传播实验）。
4. **指标、数据与对照**：数据为已授权的 A2（scPerturb 调和 `NormanWeissman2019_filtered.h5ad`，Zenodo 10.5281/zenodo.7041849，CC BY 4.0）与 A3（GSE133344 原生处理矩阵，NCBI 对本网络限流，移入学校学术资源批次）；split 单元为扰动（guide/基因），train/holdout 不重叠；透明基线（train-only centroid，沿用 ADR-0034 形状）与参考 GRN、冻结权重 MLP 做同 split 对照；主指标六节点 MAE + 方向一致率 + Spearman；接入主链时用 WP8 配对指标做单层替换矩阵。
5. **失败能否移除**：训练产物（权重、缓存）只落在 `models/` 与独立虚拟环境，不进 Git、不进核心依赖；训练适配器为生成链外或层内可选组件，删除后 reference 链逐字节不变。
6. **用户可解释性**：六节点桥是显式代理假设，训练模型保持小规模（MLP 量级），所有映射、split 与指标在实验记录中可复查。

## 3. 冻结边界

- PyTorch 等深度学习依赖**永不进入核心包**（`pyproject.toml` 运行时依赖保持为空）；训练与 h5ad 处理只在独立虚拟环境（如 `.venv-train/`）进行。
- 训练**不进入 tick 热路径**；主链只消费训练完成、经核验写入配置的权重产物。
- 每次只训练/替换一层；首个目标固定为 L0，L1–L4 保持参考模型。
- 训练数据一律走 ADR-0021 登记与去标识聚合先例：原始数据留 `data/raw/` 或 `data/aivc/`（不入 Git），只有聚合 profile / 权重产物带完整溯源进入正式配置。
- 不宣称生物拟合、虚拟细胞级真实或疗效预测；分级术语上限仍为 `reference model`，直到冻结协议 + 统计 + 消融支持为止。
- 外部大模型权重（C1 Geneformer / C2 STATE）只作离线 oracle/对照，在独立环境推理，不进核心依赖；OCellus（C3）仍待公开与单独授权（ADR-0034 不变）。

## 5. 实施顺序

1. Stage 1 纯标准库锚定先行：A2/A3 真实扰动 → 六节点方向锚定 → CAR-M 式去标识聚合 profile（h5ad 读取在独立环境，MatrixMarket 路径复用 ADR-0028 流式读取形状）。
2. 首个 L0 训练实验：训练版变体 vs 参考 GRN vs 冻结权重 MLP，同 split、同指标、配对矩阵；负面结果保留。
3. 每层后续训练目标（L2 潜状态、L3 GNN）各需独立 ADR 与对照协议。

## 6. 未采用方案与回退

未采用：把 torch 加进核心依赖、在线训练 API、直接端到端训练五层、用患者结局做训练目标、删除规则基线。回退方式：删除独立环境与 `models/` 目录及相关适配器即可；核心链、冻结基线、冻结矩阵与本 ADR 之前的全部 artifact 不受影响。

## 7. 验证

- 新增训练/锚定代码必须带配对对照与确定性种子，进入 manifest 与哈希链；
- 层内替换实验构造器强制只换目标层；
- 全套 488+ 测试与 `mgba data-check` 保持绿色；冻结单 tick、100 tick、WP8/CAR-M 身份不变。
