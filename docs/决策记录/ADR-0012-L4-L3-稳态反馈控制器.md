# ADR-0012：L4→L3 稳态反馈控制器（FeedbackPolicy 第一版）

> 状态：Accepted
> 日期：2026-08-20

## 背景

1. 架构设计文档的组件表早已声明 `FeedbackPolicy`（L4→下层的低频、受约束环境反馈），但一直没有实现；“时间与闭环”一节明确写着“L4→L3 的低频反馈尚未实现，不能越过 L3/L2 直接控制 Cell”。核心原则 §3.3 要求下行约束流必须慢于上行局部动力学、可审计、受安全边界限制，且 L4 只能改变环境压力、资源边界或允许的调控范围。
2. MVP 计划的 E4 实验（比较无反馈、固定反馈和状态相关反馈，观察恢复稳态、震荡、锁死和恶化）自 W14 起冻结，但没有任何可运行的反馈参考模型可供实验。
3. 文献与开源调研（检索时间 2026-08-20）：
   - 生物分子积分反馈可实现鲁棒完美适应（robust perfect adaptation）：Aoki et al., *A universal biomolecular integral feedback controller for robust perfect adaptation*, Nature Chemical Biology 2019；该原理在 2024–2025 年的数字孪生/剂量控制综述中被反复引用（Aghamiri et al., *The Potential Use of Digital Twin Technology for Advancing CAR-T Cell Therapy*, 2025；Putignano et al., *Mathematical models and computational approaches in CAR-T therapeutics*, Front. Immunol. 2025；Santurio et al., *Mathematical modeling unveils the timeline of CAR-T cell therapy and macrophage-mediated cytokine release syndrome*, PLOS Comput. Biol. 2025）。
   - 饱和执行器下的积分器饱和（windup）与反饱和（anti-windup）是 2024–2025 控制会议活跃方向：Lavretsky, *Integrator Anti-Windup Design for Servo-Controllers with Position Constraints*, arXiv:2504.12207（2025）把控制障碍函数（CBF）与反饱和修正结合；HAL/wes-2024-15（2024）在微射流执行器约束下使用 anti-windup 修正控制律。
   - PhysiCell/PhysiBoSS（2024 发布的开源多尺度细胞框架）的做法是环境场级别的反馈：宏观干预改变组织场（resource/stress），由细胞自主响应，而不是逐细胞下发动作指令。这与本项目“L4 不能直接指定 L2 动作”的约束同构。
4. 结论：融合上述三个优势——积分反馈的鲁棒完美适应、back-calculation 反饱和与执行器饱和、CBF 式单调安全通道——实现一个确定性离散 PI 控制器作为第一版 `FeedbackPolicy`；它只输出 L3 环境约束（资源上限、压力下限），不触碰 L0/L1/L2 对象。

## 决定

1. 新增正式边界 DTO `FeedbackConstraint`（contracts）：L4→L3 的相邻下行约束，含两个无量纲通道：
   - `resource_ceiling`：L3 节点资源恢复的目标上限（经济通道，受 PI 控制）；
   - `stress_floor`：L3 节点压力的安全下限（安全通道，瞬时比例屏障）。
   附带审计字段：误差、积分状态、饱和标志。两者都是模型内代理，不是生理量。
2. 新增 `mgba.feedback`：
   - `FeedbackControllerConfig`：设定值 $H^\*$、增益 $K_p, K_i, K_t$、死区 $\varepsilon$、积分上限 $I_{\max}$、通道映射 $r_0, \gamma_r, r_{\min}, s_0, \gamma_s, s_{\max}$、报警阈值 $H_{\text{alarm}}$；全部在构造时做有限性与值域校验，失败即抛错（fail-fast，防崩溃）。
   - `HomeostaticFeedbackController`：离散 PI + 条件积分 + back-calculation 反饱和 + 死区 + 执行器饱和；只消费正式 `OrganismState`（相邻消费），输出 `FeedbackConstraint`。
   - `FixedConstraintPolicy`：恒定约束输出，用于 E4 的“固定反馈”对照条件。
3. L3 新增 `ConstraintAwareTissueModel` 与 `ConstraintAwareTissueConfig`：
   - 无约束（`constraint=None`）时与 `TissueEnvironmentModel` 逐字节等价（测试断言完整 `TissueState` 相等，含 source digest）；
   - 有约束时：资源恢复方程目标由 1 改为 `resource_ceiling`；压力方程加入 $\gamma_c\max(0, s_{\text{floor}} - \sigma)$ 的单调向上项。两项在约束缺省时严格退化为参考方程。
   - `TissueModel` 协议新增 keyword-only 参数 `constraint: FeedbackConstraint | None = None`；`StaticTissueModel`、`TissueEnvironmentModel`、CAR-M 适配器在收到非空约束时显式抛 `ValueError`（fail-loud，绝不静默忽略）。
4. Runner 可选注入 `feedback_policy=None`：
   - 无注入时行为与 0.2.0 位级一致（`RunnerConfig`、层配置、trace 结构、checkpoint schema 全部不动）；
   - 有注入时：仅在 L4 观测 tick 调用 `policy.observe(organism, logical_time)`；约束从下一个 tick 开始进入 L3（同 tick 的 L3 不使用由自身输出刚算出的约束，保证因果方向）；
   - 约束进入 L3 `TissueState.metadata.source` 摘要，逐 tick 哈希链自动留痕；
   - checkpoint 不保存控制器状态：恢复时按 checkpoint 内 `l4_observations` 确定性重放重建控制器状态，checkpoint schema 与字段集不变。`RunnerCheckpoint` 的 `model_versions` 允许可选的 `feedback` 键。
5. E4 反馈实验（`FeedbackExperimentRunner`）：同一场景与种子下配对运行 3 条件：
   - `no_feedback`：无注入基线（与 0.2.0 位级一致）；
   - `fixed_feedback`：`FixedConstraintPolicy`，检验“环境改变本身”的效应；
   - `state_feedback`：`HomeostaticFeedbackController`，状态相关反馈。
   复用 WP8 的配对比较机制（逐层平均绝对距离、L4 有向差值、首次传播 tick），保存 raw/derived artifact。
6. 新增 CLI：`mgba feedback-experiment`（E4 矩阵）与 `mgba feedback-benchmark`（读取仿真数据生成脚本产出的 spec，对每个场景运行 E4 并汇总）。
7. 新增仿真数据生成脚本 `scripts/synthetic_feedback_benchmark.py`：无真实数据时生成确定性场景集（异质基因组、多种拓扑、多档损伤/资源压力）与基准 spec，同参数输出字节级可复现。

## 数学原理

慢时钟观测 $t_k = 1 + 10(k-1)$ 处读取稳态 $H_k \in [0,1]$，设定值 $H^\* \in (0,1)$，误差

$$e_k = \mathrm{dz}_\varepsilon(H^\* - H_k),\qquad \mathrm{dz}_\varepsilon(x) = \begin{cases} x, & |x| > \varepsilon \\ 0, & |x| \le \varepsilon \end{cases}$$

死区 $\varepsilon$ 抑制设定点附近的抖动（limit cycle）。

**经济通道（PI + back-calculation 反饱和）**：

$$\tilde u_k = K_p e_k + I_k, \qquad u_k = \mathrm{sat}(\tilde u_k, 0, 1)$$

$$I_{k+1} = \mathrm{clip}\bigl(I_k + K_i e_k + K_t (u_k - \tilde u_k),\ -I_{\max},\ I_{\max}\bigr)$$

其中 $K_t(u_k - \tilde u_k)$ 是 back-calculation 反饱和修正项（Aström–Hägglund 形式；Lavretsky 2025 的 CBF 反饱和处理同一类饱和问题）：执行器饱和时 $\tilde u_k$ 越界，修正项把积分器拉回可行域，避免 windup 导致的恢复迟滞。对恒定扰动 $d$，一阶线性闭环下积分作用给出 $e_k \to 0$ 的鲁棒完美适应（Aoki et al. 2019 的离散对应）。

**通道映射**：

$$r_k = \mathrm{clamp}(r_0 - \gamma_r u_k,\ r_{\min},\ 1) \quad\text{（资源上限）}$$

$$s_k = \min\bigl(s_{\max},\ s_0 + \gamma_s\,\mathrm{ReLU}(H_{\text{alarm}} - H_k)\bigr) \quad\text{（安全下限）}$$

安全通道无记忆、单调、无 windup 风险，等价于对 $H_k \ge H_{\text{alarm}}$ 的单调屏障（CBF 思想的离散化）：稳态越深地跌破报警线，微环境压力地板越高，迫使下层进入保守状态。

**L3 约束作用**（每节点）：

$$R_{t+1} = \mathrm{clamp}\bigl(R_t + \rho(r_k - R_t) - g\,c_t\bigr),\qquad
\Sigma_{t+1} = \mathrm{clamp}\bigl(\Sigma_t' + \gamma_c\max(0, s_k - \Sigma_t')\bigr)$$

其中 $\Sigma_t'$ 是参考压力方程的右端。$r_k = 1, s_k = 0$ 时两式严格退化为 0.2.0 参考方程。

## 结果

- 核心原则 §3.3 的下行约束流第一次有了可运行、可审计、默认关闭的参考实现；E4 从纸面实验变为可执行协议。
- 基线不变性：无反馈注入时 `mgba simulate` 的实验 ID、历史摘要、终点结局与 0.2.0 完全一致（`mgba-06a3c6124501f1d6` / `4b008f6c…` / `FAILED`），冻结矩阵身份不受影响。
- 控制器默认参数未经拟合；E4 结果（无论恢复、震荡还是恶化）都是 reference model 内的负/正面基线，不构成稳态恢复或临床剂量宣称。科学等级不变。

## 回退

删除 `mgba/feedback.py`、`FeedbackConstraint`/`FeedbackPolicy`、`ConstraintAwareTissueModel`、runner 的可选注入、E4 实验与 CLI、对应配置与文档条目即可回到 0.2.0 能力；所有冻结基线不依赖本次新增代码。
