# ADR-0005：L3 第一版组织与微环境动力学

> 状态：已接受  
> 日期：2026-08-18  
> 作用范围：WP5 L3 Tissue / Environment reference model

## 背景与研究问题

当前 L3 只聚合 Cell 均值和边密度，没有每个节点的环境状态，也不能把资源消耗、修复或分泌转化为下一步局部环境。WP5 要回答：

> 多个 Cell 的局部动作在固定邻域图上如何改变资源、压力和信号场，并进一步形成可追踪的组织级状态？

本工作包只升级 L3。L0–L2 和 L4 保持稳定基线。STEN 动态拓扑、语义消息、GNN 和空间网格不进入第一版。

## 静态有向组织图

组织使用无自环、无重复边的有向图。边 `(source, target)` 表示 `source` Cell 的分泌可以影响 `target` 的下一步局部信号。

- 拓扑在 WP5 轨迹中固定；
- 所有边端点必须属于当前 Cell 集合；
- Cell ID、节点环境和动作必须一一对应；
- STEN 仍是独立 L3 子系统，后续通过相同 Tissue 契约做对照。

## 节点环境状态

每个 Cell 对应一个 `TissueNodeState`：

| 字段 | 范围 | 含义 |
|---|---:|---|
| `stress` | `[0,1]` | 更新后的局部压力/损伤 |
| `resource_level` | `[0,1]` | 更新后的局部可用资源 |
| `signal` | `[0,1]` | 邻域分泌形成的局部信号 |

节点状态可转换成下一 L2 tick 的 `LocalEnvironment`，但 L3 不读取 L0/L1 内部对象。

## 更新规则

对节点 `i`，先更新资源：

```text
resource_i(t+1)
  = clamp(
      resource_i(t)
      + 0.10 * (1 - resource_i(t))
      - 0.60 * resource_consumption_i(t),
      0, 1
    )
```

然后计算所有指向 `i` 的入邻居均值。无入邻居时均值为 0：

```text
incoming_stress_i = mean(stress_j(t) | j→i)
incoming_secretion_i = mean(secretion_j(t) | j→i)
```

压力更新：

```text
stress_i(t+1)
  = clamp(
      0.75 * stress_i(t)
      + 0.10 * incoming_stress_i
      + 0.20 * (1 - resource_i(t+1))
      + 0.30 * apoptosis_i(t)
      - 0.60 * repair_effort_i(t),
      0, 1
    )
```

信号更新：

```text
signal_i(t+1)
  = clamp(
      0.20 * signal_i(t)
      + 0.80 * incoming_secretion_i,
      0, 1
    )
```

所有节点同步读取 `t` 时刻组织状态和当前 L2 动作。资源缺失提高局部压力，修复降低压力，凋亡提高压力，分泌只沿入边影响目标。

## TissueState

`TissueState` 保存：

- 版本化节点状态和固定边；
- Cell 数、边密度；
- 平均激活、活力、资源和信号；
- 死亡比例、修复活动；
- 协调信号与组织损伤。

组织损伤在批量实验前冻结为：

```text
tissue_damage
  = clamp(
      0.60 * mean_node_stress
      + 0.40 * (1 - mean_cell_viability),
      0, 1
    )
```

`coordinated_signal = mean_node_signal`。这些是 reference 指标，不是组织学测量。

## 初始状态与时间

首个 L3 tick 消费当前传给 L2 的 `LocalEnvironment` 作为初始节点场；后续 tick 只消费上一 `TissueState`。不能同时传入两套互相冲突的环境状态。

`TissueState` 的节点值代表本次 CellAction 应用后的环境，可转换为下一逻辑时间的 `LocalEnvironment`。当前五层 Runner 仍只推进一个 tick；WP7 才闭合持续循环。

## 固定参数

| 参数 | 值 |
|---|---:|
| resource recovery | 0.10 |
| consumption gain | 0.60 |
| stress retention | 0.75 |
| stress diffusion | 0.10 |
| resource stress gain | 0.20 |
| apoptosis stress gain | 0.30 |
| repair stress reduction | 0.60 |
| signal retention | 0.20 |
| secretion coupling | 0.80 |
| damage stress weight | 0.60 |
| damage viability weight | 0.40 |

参数保存在独立 L3 JSON 中，模型版本包含配置摘要。这些值没有从真实组织数据拟合。

## 验收与失败判据

1. 同一节点状态、图和动作产生完全相同的组织轨迹；所有场与聚合指标保持在 `[0,1]`；
2. 在 `A→B` 图上，A 分泌提高 B 的下一步信号，但不直接提高 A 信号；
3. 资源消耗只直接降低本节点资源，资源恢复在无消耗时生效；
4. 相同初态下，修复动作降低压力，凋亡动作提高压力；
5. 改变 `CellAction` 分布必须改变 `TissueState`；
6. 每个 Tissue 节点能生成同 Cell ID 的下一步 `LocalEnvironment`；
7. 未知节点、自环、重复边、Cell/Action/环境 ID 不一致或轨迹中改变静态边必须失败；
8. 配置缺字段、非有限值、越界权重或损伤聚合权重不和为 1 必须失败；
9. 五层 Runner 中 L0 修复敲低必须改变 L2 动作/死亡，再改变 L3 节点状态、组织损伤和 L4。

## 备选方案

1. 继续只做均值聚合：不能生成下一步局部环境，拒绝作为默认 L3。
2. 二维连续空间场：需要位置、边界条件和数值扩散器，推迟。
3. STEN 动态 rewiring：应在固定图 reference model 稳定后作为 E5 对照，推迟。
4. GNN：当前没有训练目标或数据，且不应替代明确的组织更新方程，拒绝进入 WP5。

## 影响、局限与回退

- `TissueState` 增加节点、边、资源、信号、死亡和修复字段；`TissueModel` 增加上一状态与初始局部环境入口。
- 旧均值聚合器以 `StaticTissueModel` 保留，可通过依赖注入恢复。
- 当前 Cell 不移动、不增殖，图不重连，也没有真实空间、力学或扩散单位；不得声称真实组织动力学或涌现。
