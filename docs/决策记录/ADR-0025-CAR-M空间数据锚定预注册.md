# ADR-0025：CAR-M 空间 L3 数据锚定预注册

- 状态：预注册已接受；许可/预算已核验且用户已授权，下载受网络阻塞（ADR-0028 修订最小文件集）
- 日期：2026-08-21
- 所属层级：L3 数据锚定与实验基础设施
- 关联：ADR-0023、ADR-0024、ADR-0021

## 1. 问题

ADR-0023 已把坐标、三通道局部场和空间邻域纳入正式 trace/checkpoint，但参数仍是无量纲手工 reference rules。ADR-0024 进一步证明：当前模型内的 L4 差异主要由场耦合和邻域定义产生，而单纯移动几乎不产生公共状态效应。

因此“继续把模拟器做复杂”不是下一步。需要用真实空间数据给最关键的两个 L3 机制建立可证伪的聚合统计目标，同时保留固定图和完整空间 reference model 作为对照。

## 2. 新能力准入六问

1. **属于哪一层？** L3；原始数据处理位于生成链外，聚合统计只约束 L3 场与拓扑。
2. **替换/增强什么基线？** 增强 ADR-0023 的手工空间参数，不替换固定图 `CarmTissueModel`，也不删除未标定空间 reference。
3. **回答什么问题？** reference model 的局部场异质性、空间自相关、细胞距离与邻接结构是否落在真实乳腺肿瘤数据的可观察范围内？
4. **如何判断有效？** 使用下载前冻结的 CV、空间自相关、梯度、区域方差、距离分位数、邻接富集和 mixing score；校准/holdout 分离，报告三条件配对和负面结果。
5. **失败能否移除？** 可以。数据 adapter、聚合 artifact 和校准配置均为 L3 可选项；删除后固定图、空间 reference 和冻结实验身份不变。
6. **能否解释？** 所有指标均为可审计聚合统计；明确 spot 不是 Cell、基因集分数只是场代理、成像细胞标签依赖原研究分群。

## 3. 决策

采用两个互补的 Stage S1 数据锚点：

- Wu/Swarbrick 六例乳腺癌 Visium 的最小处理子集（≤220 MB 压缩）锚定局部场；
- Jackson 等乳腺癌 Imaging Mass Cytometry 的细胞位置和聚类（31,080,191 bytes）锚定邻域/距离。原候选肿瘤/基质掩膜不被当前冻结指标消费，已在下载前按 ADR-0028 移出最小文件集。

两者本地解压与处理总预算上限为 2 GB。具体文件、权威来源、预注册指标、许可复核和落盘规则以 `data/spatial-carm/README.md` 为唯一清单。当前只登记 `external_planned`，**不执行下载**。

Keren TNBC MIBI 和 10x Visium HD 只作为 Stage S2 候选；必须先证明 S1 聚合管线产生可解释、可复现的统计量，之后另行冻结文件清单和申请授权。

## 4. 层级和因果边界

- 外部数据不会逐 tick 进入 runner；只生成版本化、去标识的 L3 聚合 target/profile。
- 真实细胞/spot 标签不添加到 L1–L4 DTO。Cell 类型继续只由 L0 模板表达，跨类型作用只经 L3 边与环境场。
- 临床亚型、结局和疗效标签只可用于生成链外的分层描述，不得成为 L2 目标或 L4 预期答案。
- spot 级 Visium 不用于直接估计单细胞距离；单细胞距离只来自空间成像数据。
- 参数锚定只能产生 `reference model with external anchors`，不能声称数字生命、临床预测或生物真实复现。

## 5. 成功与停止条件

成功必须同时满足：

1. 下载文件许可、URL、字节数和 SHA-256 完整；
2. 聚合脚本对相同原始文件字节级重建；
3. calibration/holdout 划分和指标在读取结果前冻结；
4. 校准模型在 holdout 至少一个预注册场指标上优于空间 reference，且其余指标没有超过预注册退化界限；
5. Jackson 跨模态邻域统计只用于外部核验，不回流挑参数；
6. 固定图、空间 reference、冻结 CAR-M 21-run 身份不变。

若 holdout 不改善，结果记为“未锚定”，停止增加参数并审查代理映射；不得用更多自由度追逐数据。

## 6. 当前证据和限制

- 机制选择来自一次确定性 reference-model 因子审计，不是生物效应量。
- Wu 数据是 spot 级空间转录组；细胞混合与反卷积误差必须显式报告。
- Jackson 数据是蛋白成像与原研究聚类；标签不等于 M-GBA L0 模板的真实对应。
- 两个 Zenodo 记录的 Rights 已于 2026-08-21 通过官方 API/DataCite 元数据核验：Wu 为 CC BY 4.0，Jackson 为 CC BY 1.0 Generic。五文件共 241,284,013 bytes；用户已授权，但当前环境无法连接 Zenodo，尚无文件落盘。
- 尚无任何外部文件下载、聚合或拟合结果。

## 7. 回退

删除 `data/spatial-carm/`、本 ADR 和 `data/registry.json` 中的 planned 条目即可回到 ADR-0024 状态。该回退不触及任何运行时代码、DTO、模型配置或已有 artifact。
