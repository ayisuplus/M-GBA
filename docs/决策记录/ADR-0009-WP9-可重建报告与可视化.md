# ADR-0009：WP9 可重建统计表、图表与只读报告

> 状态：已接受  
> 日期：2026-08-18  
> 作用范围：WP9 raw artifact 校验、CSV、SVG 与静态 HTML 报告

## 背景与研究问题

WP8 已保存 `matrix-7da4137aa39d5122` 的 21 份完整 raw run 和一份派生摘要。若图表直接复制摘要数字或由 Notebook 手工编辑，就无法证明展示与原始轨迹一致。WP9 要回答：

> 能否只用冻结 manifest 和 raw JSON，一条命令重建全部结果表与图，并在输入损坏时失败？

报告是只读观察层，不导入或调用任何 L0–L4 模型，也不改变 checkpoint、raw trace 或实验结论。

## 权威输入

报告构建器只接受：

```text
<matrix-root>/manifest.json
<matrix-root>/raw/<condition>/seed-<seed>.json
```

`derived/summary.json` 不是权威输入，只用于人工对照。构建器必须逐条验证 manifest 中记录的相对路径、condition、seed、experiment ID、history digest、tick 数和 matrix ID。路径解析后必须仍位于 matrix root 内。

## 从 raw 重算

报告使用 ADR-0008 冻结的同 seed 配对定义，从 raw tick 重新计算：

- L0–L4 终点平均绝对效应；
- 每层第一次大于 `1e-12` 的差异 tick；
- 五个终点 L4 有向差值；
- 每个条件/seed 的 L3 tissue damage、mean viability、mean resource 时间序列；
- 每个计划 L4 观察和终点观察的五个表型指标与 outcome。

构建器不得读取 `derived/summary.json` 填充这些值。若 reporting 公式未来变化，必须提升 report schema 版本并保留旧输出。

## 冻结输出

默认写入 `<matrix-root>/derived/report/`：

```text
report-manifest.json
condition-summary.csv
layer-effects.csv
metric-effects.csv
tissue-timeseries.csv
l4-observations.csv
layer-effects.svg
repair-path.svg
tissue-damage.svg
metric-effects.svg
report.html
```

CSV schema：

- `condition-summary.csv`：condition、kind、seed 数、outcome 计数、五个平均终点差值；
- `layer-effects.csv`：condition、kind、seed、layer、终点效应、首次差异 tick；
- `metric-effects.csv`：condition、kind、seed、L4 metric、有向差值；
- `tissue-timeseries.csv`：condition、seed、tick、damage、viability、resource；
- `l4-observations.csv`：condition、seed、tick、是否终点观察、五个 L4 指标、outcome。

浮点 CSV 使用稳定的 12 位有效数字；行排序由冻结条件顺序、seed、tick 和层级决定。

## 图表

第一版使用 Python 标准库直接生成可审计 SVG，不引入 plotting 依赖：

1. `layer-effects.svg`：六个非 baseline 条件在 L0–L4 的平均绝对效应，使用标明下限的对数轴以同时显示小扰动和大消融；
2. `repair-path.svg`：`repair_kd_000` 的 L0→L4 平均效应路径，直接标注各层数值；
3. `tissue-damage.svg`：seed 42 下七个条件的 tissue damage 逐 tick 曲线；
4. `metric-effects.svg`：六个条件的五项终点 L4 有向差值，使用以 0 为中心的共享轴。

每张 SVG 必须包含 `<title>`、`<desc>`、轴标题、单位/尺度说明和文本图例。颜色只编码条件/层级，并始终配合文字标签；报告在不运行 JavaScript时仍完整可读。

## 只读 HTML

`report.html` 是相对路径引用上述 SVG/CSV 的静态页面，包含：

- matrix ID、运行数、seed 和科学边界；
- 条件结果表；
- 四张图；
- raw/derived 文件说明。

页面不 fetch 数据、不调用模型、不提供调参控件，也不写回任何文件。它是研究证据的观察入口，不是仿真控制台。

## 确定性与重建

`report-manifest.json` 保存 source matrix ID、source manifest digest、report schema、每个生成文件的 SHA-256。相同 raw 输入反复构建必须产生字节相同的 CSV/SVG/HTML 和相同文件摘要。

派生文件允许由构建命令覆盖，因为它们可重建；raw/manifest 永远不修改。删除任意派生图后再次运行命令必须恢复完全相同的文件。

## CLI

新增：

```text
mgba report --matrix-root artifacts/matrix-7da4137aa39d5122
            [--output-dir PATH]
```

命令打印 source matrix ID、报告目录和文件摘要，不启动 Web 服务。

## 验收与失败判据

1. 构建器在不读取 `derived/summary.json` 的情况下生成 5 个 CSV、4 个 SVG 和 1 个 HTML；
2. CSV 中包含 18 个 seed 配对比较、L0–L4 效应、传播 tick 和全部 21 条时间轨迹；
3. 相同输入重复构建产生相同 report manifest 和文件摘要；
4. 删除图表后可由同一命令字节级重建；
5. raw experiment ID/history/seed/condition/path/tick 数与 manifest 不符时失败；
6. 图表数值与 raw 重算 CSV 一致，不能手工录入；
7. HTML 只读且不依赖网络、Notebook 或 JavaScript；
8. `mgba report`、全部测试、单 tick、多速率、实验矩阵和 STEN smoke 门禁全部通过。

## 备选方案

1. Matplotlib/Plotly：可更快绘图，但当前图简单，新增依赖不值得；先用标准库 SVG。
2. Notebook 作为唯一报告：执行状态隐式且难以空环境复现，拒绝。
3. 直接读取 derived summary：不能证明从 raw 重建，拒绝。
4. 把图表逻辑接入 Runner：会让观察代码影响核心计算，禁止。
5. 交互式仿真面板：WP9 只需只读证据，推迟。

## 影响、局限与回退

- reporting 模块只依赖 JSON/CSV/SVG/HTML 标准库，不影响核心模拟依赖。
- 当前图展示确定性 seed 重复，不提供不成立的误差条或显著性标记。
- 对数效应图的显示下限必须明确标注，零效应仍在 CSV 中保留为精确 0。
- 若报告代码有误，删除 `derived/report/` 后从 raw 重新生成；无需修改或回退任何原始运行。
