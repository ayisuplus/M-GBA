# ADR-0037：L0 扰动响应首次训练实验契约

- 状态：契约已接受（2026-08-28，训练前预注册）
- 日期：2026-08-28
- 影响范围：生成链外 L0 训练评估（`.venv-train` 训练段 + 核心核验段）；产物落 `models/` 与 `data/aivc/derived/`
- 不影响：五层 DTO/Protocol、`ReferenceCrossScaleRunner`、核心零依赖身份、全部冻结基线与矩阵；本实验**不**把预测接入 runner

## 1. 背景与准入

ADR-0035 把首个训练目标固定为 L0 扰动响应；ADR-0036 已产出实证 target `norman-perturbation-profile-0a0aa914dc9fb080`（236 单元六节点向量 + train-only 质心基线）。本 ADR 冻结首次训练实验的任务、模型、超参、对照、通过规则与产物边界。训练前不定下这些，不得开始。

六问：L0 层外训练评估（不改层模型）；候选增强对象是未来的 L0 训练变体（本实验只评估不接链）；研究问题为"扰动身份 → 六节点响应"是否可学且优于透明基线；指标为同 split 的 MAE/方向一致率/Spearman，对照为 train-only 质心与 ridge；失败则保留负面结果并删除产物即可回退；任务规模与模型规模匹配（236 样本 ↔ ~5k 参数），全部选择可复查。

## 2. 冻结任务与数据

- 输入编码：单元名按 `_` 切分为成分基因；单基因 = 该成分 one-hot + combo 标志 0；组合 = 成分 one-hot 均值 + combo 标志 1。成分词表 = 全部单元成分的去重排序集合（规则冻结，数量由数据决定并写入报告）。
- 输出：六节点 log2FC 向量（profile 的 `six_node_vector`，ABSTRACT_GENE_NAMES 顺序）。
- 拆分：与 Stage 1 完全相同的 digest 规则与 salt（`mgba-aivc-norman-anchor-2026-08-28`），train 188 / holdout 48；holdout 不参与任何训练、选择或早停。

## 3. 冻结模型与超参（训练前冻结，不因结果调整）

| 项 | 冻结值 |
|---|---|
| 质心基线 | train 单元六节点均值（与 Stage 1 质心相差须 <1e-12，作交叉核验） |
| ridge 基线 | 闭式解 `(XᵀX + λI)⁻¹XᵀY`，λ = 1.0，无截距外特征处理 |
| MLP | 输入 (V+1) → 32（tanh）→ 6（线性） |
| 优化 | Adam，lr = 1e-3，weight_decay = 1e-4，MSE，全批量，3000 epoch |
| 种子 | torch 42，numpy 42 |
| 设备 | **CPU 单线程**（torch.set_num_threads(1)；GPU/cudnn 非确定性不入本实验） |

## 4. 通过规则（ADR-0034 形状）

- 通过：holdout 六节点 MAE 严格低于质心基线 **且** 严格低于 ridge 基线（两处差值均 >1e-12）。
- 任一不满足即记"未通过"，数值原样保留；方向一致率与 Spearman 完整报告但不进入通过规则。
- 方向一致率/Spearman 若反而退化，必须在记录中显式讨论。

## 5. 产物与边界

- `scripts/train_l0_perturbation_response.py`（仅 `.venv-train`）写出 `mgba-l0-response-predictions-0.1`：三预测器全部 236 单元预测向量、训练溯源（种子/epoch/最终 train loss/权重 SHA-256/成分词表数）。权重文件落 `models/`（不入 Git）。
- 核心核验段：`mgba l0-training-evaluate` 重算指标、判定通过规则、产出 write-once `mgba-l0-training-evaluation-0.1` 并登记 registry。
- 边界：本实验离线；预测向量**不**进入 runner、不改 L0 配置（接链属后续单独 ADR）；Norman 为 K562 CRISPRa 数据，不得外推；术语上限 `reference model`。

## 6. 未采用方案与回退

未采用：GPU 训练（非确定性）、基因级 4,267 维输出（236 样本欠定）、早停/验证集调参、组合交互项、把 ridge/质心包装成"模型"。回退：删除脚本、`models/` 与评估 artifact 即可；主链与全部冻结实验不受影响。

## 7. 验证

测试覆盖：预测文件 schema/身份门禁、质心交叉核验（>1e-12 偏差拒绝）、通过规则全真/全假/平手分支、负结果保存、write-once、CLI 往返；全套既有测试与 `mgba data-check` 保持绿色。
