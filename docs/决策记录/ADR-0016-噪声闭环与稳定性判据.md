# ADR-0016：噪声下的闭环控制——E4×E3 随机反馈实验与稳定性判据

> 状态：Accepted
> 日期：2026-08-20

## 背景

1. MVP 计划 E4 要求"比较无反馈、固定反馈和状态相关反馈；观察系统能否恢复稳态，或是否出现震荡、锁死和恶化"。ADR-0012 已交付反馈控制器与 E4 确定性对照，ADR-0015 已交付种子化转录噪声与 E3 多种子集合——但两者尚未组合：**控制器在噪声扰动下的行为（能否恢复稳态、是否震荡/锁死）从未被测量**。控制理论上这正是闭环鲁棒性问题：积分反馈在确定性模型中给出完美适应，在噪声/未建模动态下可能震荡（Aoki et al. 2019 的鲁棒完美适应；Filo et al. 2026 的传感器型 antithetic integral controller 综述确认噪声鲁棒性是当前活跃方向；ETH Cybergenetics 教程确认积分反馈是鲁棒稳态调节的充要结构）。
2. 核心原则 §3.3 要求下行流可审计、慢于上行动力学；AGENTS §4 要求震荡/锁死/恶化等动力学宣称必须有预注册判据。当前没有任何模块能从轨迹中判定"震荡/锁死"。
3. 结论：组合 ADR-0012 控制器与 ADR-0015 噪声模型，新增随机闭环实验与预注册稳定性分级，把 E4 从"确定性对照"推进到"噪声下的鲁棒性测量"。

## 决定

1. 新增 `mgba.closed_loop_experiments`：三条件随机闭环矩阵：
   - `stochastic_open_loop`：噪声 L0 + 参考 L3、无反馈（随机开环对照）；
   - `stochastic_closed_loop`：噪声 L0 + `ConstraintAwareTissueModel` + `HomeostaticFeedbackController`（噪声闭环）；
   - `deterministic_closed_loop`：确定性 L0 + 同一控制器（隔离噪声对闭环的效应）。
   复用 `build_feedback_runners` 与 WP8 配对比较指标；构造器强制闭环两条件仅差 L0 噪声（或仅差反馈注入）。
2. 新增预注册稳定性分级（对每 run 的慢时钟 homeostasis 观测序列 $h_1..h_K$，$K$ 为 L4 计划观测数）：

   一阶差分 $d_k = h_{k+1}-h_k$，变号数 $\phi = \#\{k : d_k d_{k+1} < 0\}$，振幅 $s = \mathrm{std}(h)$，趋势 $\Delta = h_K - h_1$。分级阶梯（按序判定）：

   1. `insufficient_observations`：$K < 3$；
   2. `oscillation`：$\phi \ge \phi_{\min}$ 且 $s \ge a_{\min}$；
   3. `lock`：$s \le \ell_{\max}$；
   4. `recovery`：$\Delta \ge \delta_{\text{rec}}$ 且 $h_K \ge h_{\text{rec}}$；
   5. `deterioration`：$\Delta \le -\delta_{\text{det}}$；
   6. `indeterminate`：其余。

   阈值全部预注册在 `configs/experiments/closed_loop_stochastic.json`。
3. 新增 `mgba closed-loop-experiment` CLI 与 `scripts/synthetic_closed_loop_benchmark.py`（复用共享数据集）。

## 结果

- E4 问题（恢复/震荡/锁死/恶化）第一次有可执行的测量协议；噪声下的闭环鲁棒性从纸面问题变为可度量结果。
- 不变量：$\sigma_\eta=0$ 的随机开环条件与确定性无反馈运行位级一致（测试断言）；确定性 L0 + 无反馈仍是 0.2.0 冻结基线。
- 稳定性分级是 reference model 内的诊断输出；"恢复稳态"分级不构成生物学稳态宣称（AGENTS §4）。

## 回退

删除 `closed_loop_experiments.py`、对应配置/CLI/测试/脚本与文档条目即可回到 ADR-0015 状态；ADR-0012/0015 的模块本身不依赖本次新增代码。
