# ADR-0048：管线证伪对照（falsification battery）契约

- 状态：三组对照已完成——对照 1、2 判据成立，对照 3 判据不成立并按 §4 如实登记（2026-09-11）
- 日期：2026-09-11
- 影响范围：生成链外阴性对照评估；新脚本落 `scripts/`，产物落 `artifacts/falsification/`，实验记录落 `docs/实验记录/`
- 不影响：ADR-0001–0047 全部冻结产物与身份、五层契约、核心零依赖、参考基线；`src/`、`tests/`、`configs/`、已有 `artifacts/` 一律不修改；本 ADR 不做接链、不撤销任何历史 verdict

## 1. 背景与准入

项目评估发现：迄今为止所有"通过/效应"主张（ADR-0037 的 L0 训练 passed、WP8 矩阵的跨层效应与传播 tick、ADR-0027 的空间锚定同指标评估）都缺少**证伪性阴性对照**——即没有证据证明管线本身不会在无信号输入上产生假阳性。若评估器对打乱标签、错位拼接或随机目标仍输出"通过"，则历史 pass 门禁是空洞的（vacuous），必须如实记录并据此下调相应主张的证据等级。

本 ADR 在跑任何对照计算之前，预注册三组阴性对照的确定性派生方式、判据阈值、失败登记规则与产物 schema。

六问：层外评估（不改任何层模型与 runner）；增强对象为评估管线本身的可信度；研究问题为"现有 pass/效应指标在无真实信号时是否仍会假阳性"；指标与通过规则见 §3（每组对照各有预注册判据）；任一对照判据不成立即保留负面结果并按 §4 登记；全部打乱/置换派生方式、阈值、schema 计算前冻结。

## 3. 冻结协议

### 3.1 对照 1：标签打乱（label-shuffle，仅 `.venv-train`）

- 脚本 `scripts/train_l0_label_shuffle_control.py`：与 ADR-0037 原始脚本逐行同构，**唯一差异**是训练集扰动→响应标签在训练前经确定性打乱。
- 打乱派生（冻结）：对 profile 顺序下的 188 个 train 单元 u_0…u_187，计算键 k_i = `sha256("mgba-adr-0048-label-shuffle-v1|" + profile_sha256 + "|" + u_i)`；令 σ = 按 k_i 升序的 argsort（一个 188 元置换）；打乱后第 i 个 train 行的目标 = 原第 σ(i) 行的目标。特征、holdout、split、角色一律不动。
- 超参逐字沿用 ADR-0037（SEED=42、HIDDEN=32、Adam lr=1e-3、weight_decay=1e-4、MSE 全批量、EPOCHS=3000、CPU 单线程、ridge λ=1.0 无截距）。**不降 epoch**；若时间盒（20 分钟）内跑不完，如实登记 `incomplete` 与已完成核验，不为完成而改超参。
- 质心交叉核验保留：打乱是 train 标签多重集的置换，均值不变，故与 profile `centroid_train_only` 的 1e-12 交叉核验必须仍通过；不通过 = 脚本缺陷，停手调查。
- 评估在脚本内完成（不触发核心 `l0-training-evaluate`，避免触碰 registry）：holdout 上三预测器六节点 MAE 与两处 margin。
- **预注册判据**：打乱后 MLP 的 holdout MAE 对质心与 ridge 的双胜 margin 必须**不再同时 >1e-12**（即 ADR-0037 通过规则在打乱数据上不成立）→ 判据成立，ADR-0037 pass 门禁非空洞。若打乱后仍满足双胜 >1e-12 → 判据不成立，ADR-0037 的 passed 判为 vacuous，如实记录并登记为负面结果。

### 3.2 对照 2：层置换（layer-permutation，纯标准库，`.venv`）

- 脚本 `scripts/exploratory_layer_permutation_control.py`：独立实现 WP8 距离/传播口径（只读 raw JSON，不 import 核心包亦可；允许只读参考 `src/mgba/experiments.py` 口径）。
- 拼接规则（冻结）：非 baseline 条件 6 个（repair_kd_000、repair_clamp_050、repair_oe_100、l1_static、l2_static、l3_static）的全部有序供体对 (A, B)，A≠B，共 30 对 × 3 种子 = 90 条混合 trace；混合 trace 每 tick 的 L0、L1 段取自供体 A 同种子 trace，L2、L3、L4 段取自供体 B 同种子 trace（任务指定的"A 的 L0–L1 段接 B 的 L2–L4 段"形状；全枚举代替抽样，无需随机数）。每条混合 trace 与同种子 baseline 配对，重算 5 层效应距离与传播 tick。
- 实现核验锚（先于判据计算）：重算 18 条真实配对，逐层距离与冻结 derived summary 的差必须 ≤1e-12，否则判脚本实现缺陷，停手调查。
- **预注册判据**（对照通过 = C2-1 ∧ C2-2 同时成立；C2-3 为预注册的描述性分界，如实报告）：
  - C2-1 供体保真（管线健全性）：90 条混合 trace 的全部 450 个层槽位，其距离与传播 tick 必须与对应供体真实配对的同层值一致（距离差 ≤1e-12，tick 精确相等）。不成立 ⇒ WP8 指标存在跨层污染或拼接实现缺陷。
  - C2-2 组合剖面排异（区分度主门）：90/90 混合剖面（5 距离 + 5 tick 联合）不得与 6 个真实条件剖面中任何一个相同（距离逐坐标容差 1e-12，tick 精确、None 参与比较）。不成立 ⇒ 因果不连贯的输入能复现"真实"跨层传播模式，WP8 配对指标判为无区分度。
  - C2-3 传播 tick 退化（描述性分界）：报告混合 tick 向量与真实库（4 个真实 tick 模式）的碰撞率。预注册解释带：碰撞率 <1/3 = tick 指标单独亦有区分度；1/3–2/3 = tick 口径粗糙、单独区分度有限（已知扰动条件共享全 1 模式，结构性下限约 0.2）；>2/3 = tick 指标无独立区分度，须如实写入记录。该带在计算前冻结，不因结果调整。

### 3.3 对照 3：目标置换（target-permutation，纯标准库，`.venv`）

- 脚本 `scripts/exploratory_target_permutation_control.py`：不重跑仿真；从冻结 summary 逐字提取 39 维模型投影，对置换 target 做同指标等价重算。
- 置换派生（冻结）：39 个分布槽保持 (role, metric_id, sample_count) 原位；统计七元组 (minimum, q25, median, q75, maximum, mean, standard_deviation) 整体跨槽置换——槽 i 的键 k_i = `sha256("mgba-adr-0048-target-permutation-v1|" + target_sha256 + "|" + role + "|" + metric_id)`，令 σ = 按 k_i 升序的 argsort，置换后槽 i 的七元组 = 原第 σ(i) 槽的七元组。Schema、指标集合、角色结构、值多重集全部保持；若 σ 恰为恒等（概率 ~1/39!）则按约定在盐后追加 "|retry-1" 重派生一次并记录。
- 实现核验锚（先于判据计算）：对**真实** target 用同一实现重算三 role NAE 均值，必须复现 10.347825516541054 / 12.146142329407688 / 1.3273749445952074（≤1e-12），否则停手调查。
- **预注册判据**：置换 target 的三 role NAE 均值与 39 指标总均值必须**全部严格差于**真实 target 对应值（calibration > 10.347825516541054，holdout > 12.146142329407688，external_validation > 1.3273749445952074，总均值同理）→ 判据成立，评估器有区分度。任一 role 不差 ⇒ 判据不成立，如实记录评估器在该 role 的区分度缺口；逐指标胜负计数作描述性报告。

### 3.4 确定性

三组对照的全部随机性均经上述 sha256 种子流派生；对照 2、3 必须连跑两遍验证结果 JSON 字节级一致（SHA-256 相同，临时文件随后删除）；对照 1 双跑验证预测与权重字节一致（np.savez 固定时间戳先例，ADR-0037）。

## 4. 失败时的诚实登记规则

- 任一判据不成立：结果 JSON 的 `verdict` 记 `criteria_not_met`，实验记录与 §7 结果段如实写明哪个历史主张的证据等级受影响（对照 1 → ADR-0037 passed 空洞；对照 2 → WP8 配对指标无区分度；对照 3 → 空间锚定评估器无区分度）。**不得**为使判据成立而调整派生盐、阈值或 splice 形状。
- 对照 1 时间盒 20 分钟：先小规模试跑确认管线通；完整 3000 epoch 跑不完则记 `incomplete`，写明已完成核验与每 epoch 实测耗时，其余对照照常完成。
- 核验锚（质心交叉核验、18 条真实配对复现、真实 target NAE 复现）失败不属于对照结果，属于实现缺陷：停手、修复、重跑，并在记录中写明修复次数与原因。

## 5. 产物 schema（`mgba-falsification-control-0.1`）

产物目录 `artifacts/falsification/<control_id>/`，`control_id` ∈ {`label-shuffle`, `layer-permutation`, `target-permutation`}：

- `results.json`：schema_version、control_id、adr="ADR-0048"、created_date、status（completed/incomplete）、inputs（路径+SHA-256+角色）、derivation（盐/材料串与派生规则逐字记录）、criteria（预注册判据逐字拷贝）、anchors（核验锚复算值与偏差）、results（判据相关全部数值）、verdict（criteria_met / criteria_not_met / incomplete）、scientific_boundary（"阴性对照：检验评估管线在无信号输入下是否假阳性；不构成对任何生物主张的支持或否定，不撤销历史 verdict，仅标定其证据等级"）。
- `manifest.json`：同一 schema 族，登记 results.json、脚本、关键输入文件的 SHA-256 与字节数，并记录 determinism（双跑各自 SHA-256 与 byte_identical 标志；manifest 最后写入以避免自引用）。
- 对照 1 的 MLP 权重落 `artifacts/falsification/label-shuffle/weights.npz`（np.savez，字节确定）。

## 6. 未采用方案与回退

未采用：对 holdout 一并打乱（破坏与 ADR-0037 的可比性）；对照 2 抽样供体对（全枚举 90 条已足够且免随机性）；对照 3 重跑仿真（投影已冻结，重跑只会引入 runner 变量）；对照 3 从连续分布新采指标值（置换真实值多重集是更强、更免假设的零假设）；修改核心包加 CLI（本批对照链外、一次性）。回退：删除 3 个脚本、`artifacts/falsification/`、实验记录与本 ADR 即可；核心链与全部历史 artifact 不变。

## 7. 结果段（2026-09-11 计算完成后如实填写）

三组对照全部完成，双跑字节级一致（各 manifest `determinism.byte_identical = true`）。实验记录：`docs/实验记录/管线证伪对照-2026-09-11.md`。

- **对照 1 标签打乱：判据成立（criteria_met）**。打乱后 holdout 六节点 MAE：质心 0.01287217464008745（不变，置换保持均值）、ridge 0.016463705384006395、MLP 0.014203510546627647；margin 对质心 −0.0013313359065401965、对 ridge +0.002260194837378748，双胜 >1e-12 规则不再同时满足，ADR-0037 门禁整体非空洞。诚实边界：区分度由"优于质心"腿承载，打乱后 MLP 仍优于退化后的 ridge（+0.00226），两条腿区分度不对称已记录。完整 3000 epoch 实跑约 3.4 秒，未触时间盒。产物 `artifacts/falsification/label-shuffle/`（results SHA-256 4b6214ea…）。
- **对照 2 层置换：判据成立（criteria_met，附 C2-3 边界）**。核验锚：18 条真实配对复现冻结 summary，最大差 5.55e-17。C2-1：450/450 层槽位供体保真；C2-2：0/90 混合剖面落入真实库；C2-3：tick 碰撞率 60/90 = 0.6667，落在预注册 1/3–2/3 带（tick 口径粗糙、单独区分度有限，区分度由逐层距离承载）。产物 `artifacts/falsification/layer-permutation/`（results SHA-256 87b6d41c…）。
- **对照 3 目标置换：判据不成立（criteria_not_met），按 §4 如实登记**。核验锚：真实 target 三 role 均值与 39 条 NAE 全部复现（≤1e-12）。置换 target role 均值：calibration 12.12042842782665（差于真实 10.3478 ✓）、holdout 10.233379507912382（**优于**真实 12.1461 ✗）、external_validation 16.267486217380245（差于真实 1.3274 ✓）、总均值 12.351653717756609（差于真实 8.9578 ✓）；逐指标 22/39 更差。结论：评估器在 holdout field 指标上无区分度——模型投影距真实 holdout 分布比距随机置换分布更远；该 role 的"NAE 改善"今后不能被此评估器独立佐证。calibration、external_validation 与总均值区分度正常。产物 `artifacts/falsification/target-permutation/`（results SHA-256 37dbcc44…）。

历史 verdict 均不撤销；本批对照仅标定证据等级：ADR-0037 双胜门禁非空洞（附腿级边界）、WP8 逐层距离指标非空洞（传播 tick 单独区分度有限）、空间锚定评估器的 holdout role 区分度缺口登记为待修复项。
