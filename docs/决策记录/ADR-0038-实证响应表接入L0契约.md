# ADR-0038：实证响应表接入 L0 与单层配对实验

- 状态：契约已接受（2026-08-28，实现与实验前预注册）
- 日期：2026-08-28
- 影响范围：新增 L0 层内可选变体 + 生成链外配对实验；产物落 `data/aivc/derived/` 与 `artifacts/empirical-l0/`
- 不影响：五层 DTO/Protocol、`ReferenceCrossScaleRunner` 默认链、全部冻结基线与矩阵；参考 GRN 永久默认不变

## 1. 背景与准入

ADR-0037 的 MLP 已通过冻结规则（holdout MAE 0.009494，margin +0.003378/+0.002786）。本 ADR 把训练成果以**纯数据蒸馏**形式接入 L0：核心包不 import torch/numpy，只消费通过核验的预测表。六问：L0 层内可选变体（参考 GRN 默认不动）；研究问题为"经验多节点响应模式 vs 单节点硬钳制"两种扰动语义的跨层传播差异；指标复用 WP8 配对距离与传播 tick；对照为同场景同调度的参考硬钳制臂；失败删除变体与实验即可回退；全部选择（单元、节点、剂量、语义）计算前冻结。

## 2. 冻结选择（实现前确定，不看实验结果）

- **单元**：`BAK1`（1,349 QC 细胞）。规则：train 角色 ∧ 单基因 ∧ 基因 ∈ 十集桥并集（1,362 基因）→ 细胞数最多 → 字典序。候选 18 个。
- **参考臂映射节点**：`damage_response`。规则：含该基因桥集数最多的节点；平手按 ABSTRACT_GENE_NAMES 序（BAK1 ∈ P53_PATHWAY、TNFA_SIGNALING，1:1 平 → damage_response）。
- **剂量**：两臂均 1.0；常量扰动，自第 1 个 L0 tick 起。
- **场景与调度**：`configs/multiscale_demo.json`，100 tick，scenario seeds 41/42/43（确定性重放门禁，不宣称统计重复）。
- **语义声明**：这是两种扰动*语义*的对照（经验模式 vs 硬钳制），不是疗效或生物真实性比较；BAK1 向量来自 K562 CRISPRa，幅度小（|log2FC|<0.01），预期两臂差异不对称——负面对照意义冻结在内。

## 3. 三段实现

1. **响应表蒸馏**（`mgba l0-response-table-build` → `mgba-l0-response-table-0.1`）：只在 ADR-0037 评估 artifact verdict == passed 且三重 digest 交叉一致（predictions↔profile↔evaluation）时生成；write-once。
2. **L0 变体**（`src/mgba/layers/l0_empirical.py`：`EmpiricalResponseGrnModel`）：自然动力学委托参考 `DiscreteGrnModel` 逐位复算；扰动应用分两类——抽象节点名沿用参考硬钳制（逐位等价）；表内单元名按冻结公式 `applied_i = clamp01(natural_i × 2^(dose × log2fc_i))` 逐节点应用并逐节点签发 `L0PerturbationEvent`（kind 按 natural 比较，复用现有审计形状）；未知目标 fail-closed。model_version 携带表 digest。
3. **配对实验**（`mgba empirical-l0-experiment`）：baseline / reference_clamp / empirical_response 三条件 × 3 seed；构造器强制 empirical runner 与参考 runner 仅 L0 模型不同；WP8 配对逐层距离 + 传播 tick + 终末 L4；append-only artifact `artifacts/empirical-l0/`。

## 4. 边界

预测表只含六节点浮点向量与公开扰动名（无细胞级数据）；经验响应只支持 ADR-0037 已验证的 236 个单元（CRISPRa/K562）；不新增临床主张；术语上限 `reference model`。组合单元在表中可用但本实验只用单基因 BAK1。

## 5. 未采用方案与回退

未采用：核心包加载 torch/npz 权重、runner schedule schema 变更（复用现有 `{name: dose}` 通道）、KD 语义（无 KD 数据，待 B2）、按响应幅度挑选展示单元、多单元同时扰动。回退：删除响应表、`l0_empirical.py` 与实验 artifact；默认链逐字节不变。

## 6. 验证

测试覆盖：表构建门禁（verdict 未通过拒绝、digest 篡改拒绝）、模型数学（2^x 缩放、clamp 审计、dose=0 恒等、抽象节点回退逐位等价、未知目标拒绝）、配对构造器单层门禁、baseline 身份、write-once、CLI 往返；既有全套测试与冻结身份不变。
