# 实验源码指纹复核

新生成的 `mgba-manifest-0.2` 在 `source_digest` 中记录实际安装的 `mgba/**/*.py` 字节指纹。复核当前环境：

```powershell
.\.venv\Scripts\python.exe -c "from mgba.experiment import package_source_digest; print(package_source_digest())"
```

输出必须与待复现实验 manifest 的 `source_digest` 完全相同；不同即表示源码路径、文件集合或文件字节不同，不能声称代码级精确复现。本次迁移时的指纹是：

```text
875824b7bfca273b84c5d7423b65c2248c809ef994606da99224d9a7541493ec
```

历史 `mgba-manifest-0.1` 没有源码指纹，仍可按原 ID 与报告链读取，但只能依赖对应 release、wheel 或提交快照确认源码，不能事后补造 `source_digest`。
