# 效应稳健性探索性复分析 — 2026-09-11

> **探索性诊断，不构成确认性结论。** 本记录中的所有置信区间均为**细胞维度**配对重采样（paired cell-level bootstrap）产物，刻画单次确定性实现内部逐细胞效应的离散程度，**不是**生物学重复或独立模拟重复带来的抽样不确定性。三个实验的全部 seed（41/42/43）经逐位比对确认为**确定性重放重复**（同一条件 3 个 seed 的终末逐细胞向量逐位相同），不构成统计重复；统计推断只在细胞维度进行。结果层级为探索性诊断，不支持任何确认性因果或稳健性主张。

## 1. 目的

项目所有配对矩阵实验（WP8 矩阵、CAR-M 状态条件干预、empirical-l0）的效应量均为点估计。本次复分析在**不修改任何已有 artifact** 的前提下，用细胞级配对 bootstrap 为已有效应补 95% CI、方向一致率与效应驱动集中度，回答一个探索性问题：**这些效应是细胞群体一致的，还是被少数细胞驱动的？**

分析脚本：`scripts/exploratory_effect_robustness.py`（纯标准库，argparse CLI，未 import 任何 mgba 内部 API）。

## 3. 方法

1. **逐细胞终末状态提取**：取每个 run `ticks[-1]["l2"]` 的逐细胞连续字段 `stress_load`、`viability`、`activation`（L2 的 `phase` 为离散相位，不作为主分析量）。
2. **配对设计**：同一 seed 下每个干预/消融条件 vs baseline，按 `cell_id` 取交集做逐细胞差值。三个实验全部配对的细胞交集均为全集（无细胞丢失）。
3. **seed 重复检测**：对每个条件，逐位比对 3 个 seed 的终末逐细胞向量（cell_id + phase + 三个连续字段的 repr）。**全部 12 个条件均为逐位相同** → 记录为"seed 为重放重复，合并为单次确定性实现"，每个配对只保留一份 canonical 结果（seed 41），bootstrap 随机流命名空间不含 seed。
4. **细胞级配对 bootstrap**：对差值向量做 10,000 次有放回重采样，取均值分布的 2.5% / 97.5% 百分位（线性插值）。每次重采样的随机流由 `hashlib.sha256("mgba-exploratory-effect-robustness-0.1|<experiment>|<condition>|<field>|<resample_index>")` 前 8 字节派生 `random.Random` 种子，完全确定性，不使用 `random` 模块全局状态。
5. **方向一致率**：差值符号与均值差同向的细胞比例（零差值单列，不计入同向或反向）。
6. **效应驱动集中度**：按 |差值| 降序，贡献最大的 10% 细胞（`ceil(0.1n)`，至少 1 个）占总效应绝对值的比例。
7. **L4 交叉核对**：从 raw 重算每 run 终末 `terminal_observation` 五指标（vitality / damage_burden / inflammation / homeostasis / recovery_capacity）相对同 seed baseline 的差值，与各实验 `derived/summary.json` 的 `final_metric_effects` 比对（容差 1e-9），不一致时原样记录、不覆盖。

输出 schema 版本：`mgba-exploratory-effect-robustness-0.1`。

## 5. seed 重复检测与 L4 交叉核对

- **seed 重复检测**：3 个实验、全部 12 个条件，3 个 seed（41/42/43）的终末逐细胞向量**逐位完全相同**；逐 seed 独立计算的配对结果亦字节级相同。结论：seed 为确定性重放重复，每配对合并为单次确定性实现，统计推断只在细胞维度进行。
- **L4 交叉核对**：从 raw `terminal_observation` 重算的终末 L4 指标差值与 derived/summary.json 的 `final_metric_effects` 逐值比对：**mvp-demo 90/90、carm-intervention 60/60、empirical-l0 15/15，共 165/165 个数值全部一致**（容差 1e-9，实际最大绝对偏差 0.0）。raw 重算口径与已有 derived 聚合完全吻合。
- **确定性核验**：脚本连续运行两遍，全部 5 个输出文件（summary.json、3 个 detail、manifest.json）字节级一致（cmp 验证）。

## 6. 边界声明

1. 本分析为**探索性诊断，不构成确认性结论**。
2. 所有 CI 是**细胞维度**配对重采样产物，描述单次确定性实现内部逐细胞效应的离散程度；**不是**生物学重复、不是独立模拟重复的抽样分布。全部 seed 为重放重复，不存在 seed 维度统计推断。
3. mvp-demo 与 empirical-l0 每配对仅 4 个细胞，bootstrap 均值分布至多 5 个取值，CI 极度粗糙；"CI 触及 0" 与 "集中度 1.0" 只能作为稀疏响应的诊断信号，不能作为效应不存在的证据。
4. 方向一致率与集中度依赖 cell_id 对齐与终末单时点切片，不刻画轨迹动态。
5. 本分析未修改 `artifacts/` 下任何已有目录、`configs/`、`tests/`、`src/`；输入 artifact 全程只读。
