## 3. 路径证据

`repair_kd_000` 在 tick 1 由正式 L0 钳制入口进入，L0–L4 的终点平均绝对效应依次为：

```text
L0 0.034872
  → L1 0.028567
  → L2 0.001871
  → L3 0.000682
  → L4 0.001859
```

五层首次差异都记录为逻辑 tick 1，因为同一个快速 tick 内按 L0→L1→L2→L3→计划 L4 顺序更新。这证明路径可追踪，不代表现实传播没有时间延迟。

静态替换没有改变其下方层：例如 `l1_static` 的 L0 效应为 0，差异从 L1 开始；`l2_static` 的 L0 效应为 0，L1 仅在下一 tick 通过正式 L2→L1 反馈出现很小差异；`l3_static` 的差异先出现在 L3，再经 L3→L2→L1 的相邻反馈向下传播。

## 4. 当前解释

1. 完全 repair 敲低会产生方向一致但较小的全链路恶化，说明该扰动没有被接口吞掉。
2. 0.5 硬钳制不是始终的“部分敲低”：自然表达低于 0.5 时它成为过表达，因此使用中性名称 `repair_clamp_050`。三档剂量没有形成简单单调 L4 响应。
3. L1 静态替换使终点略差，说明粗粒度分子周转在当前参数下提供了少量缓冲。
4. L2 静态替换产生远大于其他条件的改善并转为 `RECOVERED`。这不能证明静态 L2 更真实；它指出五态 L2 的累计活力、死亡吸收态或资源消耗规则是 baseline 崩溃的首要诊断对象。
5. L3 静态替换大幅降低损伤但仍为 `FAILED`，说明动态资源/压力累积对损伤负担贡献很大，同时 L4 结局还受低活力等其他量约束。
6. 所有 seed 重复完全相同，当前不能计算有意义的置信区间、p 值或涌现稳定性。
