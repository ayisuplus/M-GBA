# M-GBA 0.1.0 中文设计报告

> 项目：Multi-scale Graph Biological Architecture  
> 版本：0.1.0  
> 日期：2026-08-18  
> 科学等级：确定性、无量纲 cross-scale reference model

## 摘要

M-GBA 探索一条自下而上构建数字生命研究系统的工程路线：微观调控状态不直接决定宏观结果，而是通过 L0 基因/转录调控、L1 分子/蛋白状态、L2 细胞状态与动作、L3 组织图与微环境，最终生成 L4 宏观表型。多智能体和 STEN 只是 L2/L3 的候选技术，不是项目的总体定义。

0.1.0 实现了一个只依赖 Python 标准库的五层参考模型，具备严格相邻层契约、多速率调度、确定性检查点、扰动/消融实验和只从原始轨迹重建的报告链。实验证明 L0 repair 敲低的差异可追踪至 L4，同时暴露 L2 五态累积规则是当前默认轨迹失败的主要诊断对象。这是软件架构与模型内因果追踪结果，不是现实生物因果、临床预测或涌现证明。

## 1. 研究问题与范围

0.1.0 回答三个可验证的问题：

1. 五层是否都承担运行时计算，且主生成流中没有跳层依赖？
2. 一个只直接作用于 L0 的受控扰动，是否能通过正式边界传播至 L4？
3. 替换 L1、L2 或 L3 的参考动力学时，最终 L4 表型是否发生可量化改变？

本版本不回答真实基因调控、蛋白质结构、临床损伤修复、空间组织力学或已证明涌现。

## 2. 总体架构

| 层 | 0.1.0 参考模型 | 输入边界 | 主要输出 |
|---|---|---|---|
| L0 | 六节点确定性离散 GRN | `Genome` + `RegulatoryInput` + 上一 L0 状态 | `TranscriptState` |
| L1 | 翻译、降解、受体门控和负反馈 | `TranscriptState` + `MolecularInput` + 上一 L1 状态 | `MolecularState` |
| L2 | `QUIESCENT/ACTIVATED/REPAIRING/STRESSED/DEAD` 五态状态机 | 本 Cell 的 L1、`LocalEnvironment`、上一 L2 状态 | `CellState` + `CellAction` |
| L3 | 固定有向图上的节点压力、资源、信号动力学 | 同 ID 的 L2 状态/动作 + 上一 L3 状态 | `TissueState` + 下一步局部环境 |
| L4 | 只读表型观察器和时间窗口分类 | `TissueState` | 活力、损伤、炎症、稳态、恢复能力与结局 |

主路径固定为 `L0→L1→L2→L3→L4`。持续运行中只闭合 `L2→L1` 局部信号和 `L3→L2` 局部环境两个相邻快反馈。L4 目前是观察器，没有 L4→L3 下行控制，因此系统尚不是完整的宏观反馈闭环。

## 3. 时间、追踪与实验身份

`MultirateCrossScaleRunner` 使用无量纲整数时钟：L1/L2/L3 每 tick 更新，L0 每 5 tick 更新，L4 每 10 tick 观测，两个慢时钟都从 tick 1 锚定。每 tick 保存当前五层正式状态、输入、动作和相邻转换事件，历史使用确定性哈希链累积。

Experiment manifest 包含场景摘要、各层模型版本、运行器版本和 seed。相同输入生成相同 experiment ID；checkpoint 保存完整继续计算状态，`13 + 87 tick` 与一次 `100 tick` 的历史摘要和终点一致。

## 4. 实验设计

WP8 冻结了 7 个条件，每个条件在 seed 41、42、43 下运行 30 tick，共 21 份 raw run：

- `baseline`：五层默认 reference model；
- `repair_kd_000`：L0 repair 表达硬钳制为 0.0；
- `repair_clamp_050`：L0 repair 表达硬钳制为 0.5；
- `repair_oe_100`：L0 repair 表达硬钳制为 1.0；
- `l1_static`、`l2_static`、`l3_static`：只替换目标层的动力学。

每个非 baseline 条件只与同 seed baseline 配对。L0–L4 层效应是当前 reference 状态空间的平均绝对距离，L4 各指标另保留有向差值。这是模型诊断量，不是现实生物效应量。

## 5. 结果

冻结的单 tick experiment ID 为 `mgba-023f543fb5a130ab`。100 tick 基线的 experiment ID 为 `mgba-66654d1710f94556`，历史摘要为 `7edbf3b897983ae4d24e1537bcc6b6d8850f3933adfeb6cc78b215c56d1350dc`，最终结局为 `FAILED`。这个负面基线被原样保留，没有为演示效果调参。

WP8 matrix ID 为 `matrix-7da4137aa39d5122`。下表为相对同 seed baseline 的平均最终 L4 差值：

| 条件 | 结局 | Δ活力 | Δ损伤 | Δ稳态 | 解释边界 |
|---|---:|---:|---:|---:|---|
| `repair_kd_000` | 3 `FAILED` | -0.002460 | +0.002382 | -0.001464 | 敲低已经传到 L4，幅度较小 |
| `repair_clamp_050` | 3 `FAILED` | +0.000439 | -0.000408 | +0.000259 | 0.5 钳制对低于 0.5 的自然表达会成为过表达 |
| `repair_oe_100` | 3 `FAILED` | -0.000866 | +0.000798 | -0.000510 | 当前参数下没有简单单调剂量反应 |
| `l1_static` | 3 `FAILED` | -0.013862 | +0.013302 | -0.008233 | L1 周转在当前模型中提供少量缓冲 |
| `l2_static` | 3 `RECOVERED` | +0.469376 | -0.800620 | +0.581217 | 差异最大，指向当前 L2 累积规则 |
| `l3_static` | 3 `FAILED` | +0.010228 | -0.645599 | +0.101442 | L3 资源/压力累积对损伤有大贡献 |

`repair_kd_000` 在 L0–L4 的层效应依次约为 `0.034872→0.028567→0.001871→0.000682→0.001859`。五层首次差异均记录为 tick 1，因为快 tick 内按 L0→L1→L2→L3→L4 顺序更新；它表示软件路径可追踪，不表示现实传播瞬时完成。

## 6. 报告与可重建性

WP9 只读取 matrix manifest 和 21 份 raw run，不读取 `derived/summary.json` 填充图表。报告重算并输出 6 条件摘要、90 条逐层效应、90 条 L4 指标效应、630 条 L3 时序和 84 条 L4 观测，最终生成 5 份 CSV、4 张 SVG、1 份静态 HTML 和 report manifest。

报告构建器会重新验证 experiment ID、tick 完整性、历史哈希链、checkpoint ID 和 manifest 记录集。损坏 raw 身份或路径越界时闭锁失败；删除派生图表后重建会得到相同字节与 SHA-256。

## 7. 质量门禁

0.1.0 的自动化门禁覆盖：

- 五层 DTO/Protocol 与非相邻层拒绝；
- L0/L1 稳定性、值域、单调方向与配置指纹；
- L2 环境依赖、修复/应激分离和死亡吸收态；
- L3 边方向、局部资源、修复/凋亡压力效应和固定拓扑；
- L4 极端状态、方向性、窗口和四类结局；
- 100 tick 多速率调度、预算、checkpoint 冲突与精确恢复；
- 21-run 矩阵的完整性、层替换范围和五层扰动传播；
- raw-only 报告的确定性、删除后重建和损坏输入拒绝；
- 完整演示与明确限定范围的 fallback 演示。

## 8. 已知限制

1. 所有状态和时间均无量纲，未拟合真实数据。
2. 模型是确定性的；三个 seed 轨迹完全相同，不构成有效统计重复。
3. L3 拓扑固定，没有空间几何、力学、移动、增殖或扩散单位。
4. L4 只观察，尚未完成 L4→L3→L2→L1→L0 慢反馈。
5. 当前没有支持“群体动力学”或“涌现”的预注册证据。
6. STEN 只是独立 L3 smoke 子系统，未进入五层主运行链。
7. 结果只支持软件架构和 reference-model 内部诊断，不支持生物、药理或临床推断。

## 9. 结论与下一阶段

0.1.0 的核心产出不是“多了几个 Agent”，而是一条可执行、可替换、可追踪、可反驳的五层纵向基线。它已经能保留负面结果、定位敏感层级，并将每个结论追溯到 raw trace。

下一阶段应优先学习和完成随机过程、参数敏感性、有效重复和外部数据校准，再以新版本逐层引入 L4 反馈、GNN、动态拓扑、STEN 或 LLM policy。任何增强都必须与 0.1.0 规则基线对照，并报告它如何改变 L0→L4 的证据链。
