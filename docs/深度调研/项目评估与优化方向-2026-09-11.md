# M-GBA 项目评估与优化方向（2026-09-11）

评估范围：全部 ADR（重点 0043–0047）、docs/深度调研/报告5、可行性评估、MVP 计划、08-29 后全部实验记录、artifacts/ 全部 8 个实验目录、data/registry.json 与数据资源状态、configs/ 冻结配置、web/ 构建状态。本报告只做评估与方向建议，不构成任何生物学结论。

---

## 一、总体判断（先给结论）

1. **工程成熟度显著高于科研有效性。** 631 项测试、三条 CLI 门禁、26 条数据登记全绿（今日复验）；但所有进攻性科研路线均被预注册门禁诚实判负：KD 可学性三条路线全证伪（ADR-0039/0040/0046）、空间锚定未达成（ADR-0027/0043/0044）、跨背景外推主模型退化 7.68% 触发 No-Go（ADR-0047）。
2. **项目当前没有任何"未见扰动 × 未见背景"的确认性预测优势。** 唯一通过的 ML 结果（Norman OE，holdout MAE 0.009494）经重分层后优势集中在"成分训练见过"的单元；all-unseen 10 单元上 MLP（0.013225）不优于质心（0.012533）——是插值，不是外推。
3. **最可行的出路与报告 5 一致：收敛为"证据治理与可复现跨尺度仿真软件"论文路线。** 项目真正的差异化资产不是五层架构本身（Vivarium/PhysiCell/PhysiBoSS 已覆盖），而是"相邻层契约 + 证据分级 + 预注册门禁 + 负结果保留 + 字节级可重放审计链"这一整套 evidence-governed 工程方法。
4. **治理体系本身运行良好且产生了真实价值**：ADR-0044 主动撤回了因协议偏差（105 > 89 次评估）获得的 `improved` 结论——这种自我纠错能力正是软件论文的核心卖点。

## 三、量化短板与工程缺口（按优先级）

### 科学短板

1. **空间链完全未锚定（最大短板）**：无量纲 reference 场与真实空间分布在 30 个场指标上零重合；唯一一次标定因协议偏差作废（ADR-0044）；且 Wu/Jackson 是乳腺癌生态图谱，与 CAR-M 干预响应问题错配。邻域/拓扑指标 9/9 在界内是唯一亮点——说明**图结构层面的 reference 规则量级合理，场动力学层面不合理**。
2. **负反馈桥节点覆盖结构性缺口**：六节点桥中"负反馈"节点在 KD 宇宙仅覆盖 38 基因，限制了任何 KD 方向的语义表达力。
3. **主链多数层是无量纲 reference rules**：E3/E4/E5/closed-loop/策略替换几乎全部为 `FAILED` 负面基线或 ≤1e-4 近零效应；empirical-l0 系列全部 9–15 个 run（含 baseline）outcome 均为 `failed`，效应量都是在失败背景上的微小扰动。

### 工程缺口（今日审计新发现）

4. ~~D1-context-ood 未入 registry~~ → **今日已修复**（+8 条，data-check 26 条全绿）。
5. **carm-spatial-calibration 是唯一结构不完整的 artifact 目录**：只有单文件 summary，无 manifest.json / raw/，与项目 manifest+raw+derived 三层惯例不一致。
6. **registry 顶层缺 license/source 机器可读字段**：许可信息只嵌在 notes 散文里，无法机器审计。
7. **开源发表硬障碍**（报告 5 路线 A 前置）：无 LICENSE / CONTRIBUTING / CITATION.cff，pyproject 无许可证元数据；公开 Git 史仅约 20 次提交、集中两周、单作者——JOSS desk-reject 风险高，需 ≥6 个月公开开发史积累。
8. 仓库根有残留文件 `%TEMP%cli_oldcli_old.py` 与空目录 `%TEMP%cli_old`（疑似历史 CLI 事故残留），未清理。

## 四、优化方向（可执行，按投入产出排序）

### A. 立即可做（本周，纯工程）

1. **软件论文路线 A 的硬任务清单落地**（报告 5 已给出 90 天计划）：
   - 补 LICENSE（需所有者选定许可证，建议 MIT 或 Apache-2.0）、CONTRIBUTING.md、CITATION.cff、pyproject license 元数据、AI 使用披露声明；
   - 一键复现脚本（wheel 安装 + 605+ 测试 + 三个主示例的端到端脚本）；
   - 同类软件可执行 benchmark 矩阵（Vivarium/PhysiCell 对比维度：契约显式性、确定性重放、artifact 审计）。
2. **registry schema 升级**：为 license/source 增加结构化字段（走一个轻量 ADR + data-check 规则扩展），使许可审计机器可读。
3. **补齐 carm-spatial-calibration 的 artifact 结构**：该目录已按 ADR-0044 降级为探索性诊断，补一份 manifest.json 说明其降级身份与来源即可（不改写历史数值）。
4. 清理 `%TEMP%` 残留文件（需所有者确认后删除）。

### B. 中期实验方向（需预注册 ADR，不违反已关闭路线）

5. **新空间 target 预注册（恢复确认性空间证据的唯一合法路径）**：按 ADR-0044 的要求，用**新的、未查看过的**空间数据 target + 固定 split + 89 次硬预算 + 一次确认。候选：spatial-carm README 中已标记的 S3（Keren TNBC MIBI）/ S4（10x Visium HD）——目前状态"待调查、未申请授权"，先完成授权与许可核验即可启动。注意指标设计应吸取"场指标全部出界"的教训：考虑先把**邻域/拓扑类指标（已 9/9 在界内）**作为确认性主张，场指标仅作描述性。
6. **负反馈桥节点扩充**：独立 ADR，重新审 MSigDB Hallmark → 六节点映射，目标把负反馈节点覆盖从 38 基因提高一个量级；这是纯契约/数据工作，不违反 KD No-Go（KD 关闭的是"单敲低可学性"，不是桥本身）。
7. **OE 外推短板的决定性回答**（可选，风险自负）：报告 5 建议的 component-disjoint / context-disjoint benchmark，带早停规则——若 all-unseen 仍无稳定优势即永久回软件路线。注意这与 ADR-0047 No-Go 的关系：该 ADR 关闭的是"低秩交互模型 + 四背景"这条方法路线，不是"OE 外推"问题本身；如要做必须新 ADR 明确区分。

### C. 远期/基础设施（需资源或授权）

8. **LLM 假设提出器接入 autolab-propose（ADR-0020 Phase 2）**：提案通道已是 fail-closed 且永不自动执行，接 LLM 只改变提案来源，不改变执行门禁——这是项目方法论（人机协作 + 证据治理）最有展示价值的延伸，也是软件论文的亮点章节。需 API 授权。
9. **OCellus 权重真实对照（ADR-0034）**与 **Tahoe 完整单板可行性核查**：均卡在权重公开/网络/授权，维持监控即可。
10. **Arc H1 解封**：按 ADR-0047 预注册永久停止本轮；仅当未来有新主模型通过全部开发门槛时才重新评估。
