# M-GBA 科学性提升方案（2026-09-11）

承接《项目评估与优化方向-2026-09-11》。本文聚焦一个问题：**在现有治理框架内，如何让项目的结论更"科学"**——即从"描述性观察"升级为"带不确定性量化、经证伪检验、可外推边界明确"的证据。

## 〇、当前证据层级的诊断

项目现有证据几乎全部停在两个层级：

| 层级 | 现状 | 缺口 |
|---|---|---|
| 描述性距离（descriptive distance） | 大量：WP8 层间距离、CAR-M 效应量、空间 NAE | 无不确定性量化；3 seed 逐位相同，只是确定性重放门禁，不是统计重复 |
| 预注册 pass/fail（门禁式） | L0 训练、空间标定、ADR-0047 | 门禁回答"过不过"，不回答"效应多大、多稳、边界在哪" |
| 统计推断（CI / 检验） | 仅 ADR-0047 用了基因分块 bootstrap CI | 主链实验（WP8/CAR-M/empirical-l0/intervention）全部没有 |
| 证伪性阴性问题（falsification controls） | 只有零效应负对照（全关/仅移动） | 没有标签打乱、层置换、目标置换等"检测管线本身会不会撒谎"的对照 |
| 外推边界（extrapolation boundary） | 报告 5 重分层提示 OE 只是插值 | 没有预注册的边界测定实验 |

**核心结论：项目不缺诚实，缺的是"效应的置信区间、管线的证伪对照、结论的外推边界"三件套。** 这三件都能在不违反任何冻结协议的前提下补齐。

## 一、分级提升路线（按科学性收益 / 成本比排序）

### S1 · 效应稳健性复分析（今日已启动，纯只读，无需 ADR）
对已有 raw artifact 做**细胞级配对 bootstrap**：WP8（21 run）、state-conditioned intervention（15 run）、empirical-l0（9 run）的全部终末效应，补 95% CI 与方向一致率（多少比例的细胞同向）。
- 科学收益：把"L2 静态替换产生最大差异""晚期干预减轻 vitality 代价"从点估计升级为区间估计；检验效应是群体一致还是被少数细胞驱动。
- 性质：探索性诊断（ADR-0044 确立的合法层级），不改写历史结论，只补充不确定性刻画。

### S2 · 管线证伪对照组（falsification battery，需一个轻量 ADR）
给每条"通过/效应"主张配三个阴性对照，证明**管线本身不会产生假阳性**：
1. **标签打乱对照**：L0 OE 训练数据打乱扰动标签后重训，MLP 对 ridge/质心的优势必须消失——验证 ADR-0037 的 pass 门禁不是空话；
2. **层置换对照**：把 trace 的 L2 与 L3 段错位拼接后重算逐层效应，"传播 tick"与层间距离必须退化——验证 WP8 配对比较指标不是在测噪声；
3. **目标置换对照**：空间锚定评估器换一个随机生成的 target，NAE 必须显著差于真实 target——验证同指标评估有区分度。
- 科学收益：这是把"工程门禁"变成"科学仪器"的关键一步；任何期刊审稿人都会先问"你的对照是什么"。
- 成本：全部离线、用现有数据与脚本；训练类对照需 .venv-train 机时。

### S3 · 外推边界的预注册测定（需 ADR，报告 5 路线 B 的收敛版）
一个 ADR 同时冻结：**成分不相交（component-disjoint）重分层** + **早停规则** + **预注册判据**：
- 把 Norman 236 单元按"组合成分是否都在训练集出现过"重分层，holdout 改为纯 all-unseen；
- 判据：MLP 在 all-unseen 上同时严格优于质心与 ridge（沿用 >1e-12 margin 规则）；
- 早停：若不通过，OE 外推方向与 KD 一样正式关闭，永久回归软件路线——**两种结局都产生可发表的确定性知识**。
- 这与 ADR-0047 的 No-Go 不冲突：0047 关闭的是"低秩交互模型 × 四背景"方法路线，S3 测的是"单背景 OE 组合外推"这个更弱的问题。

### S4 · 桥覆盖与代理质量审计（需 ADR，纯契约/数据工作）
- 负反馈节点 KD 宇宙仅覆盖 38 基因——重新审 MSigDB Hallmark→六节点映射，给出每个节点的覆盖率、特异性和冗余度审计表；
- 空间三通道八基因代理（ADR-0028 冻结）做灵敏度分析：替换代理基因集时 target 指标漂移多大——回答"结论有多依赖代理选择"。

### S5 · 空间确认性证据重建（需新数据授权 + 新预注册，ADR-0044 指定路径）
- 新未查看 target（S3 Keren TNBC MIBI / S4 Visium HD，待授权）+ 固定 split + 89 次硬预算 + 一次确认；
- **指标策略修正**：邻域/拓扑指标已 9/9 在界内（NAE 1.33），场指标 30/30 出界——新协议应以邻域指标为确认性主张、场指标仅描述，避免重复"全部出界"的结构性失败；
- 同时诚实标注生态图谱数据与 CAR-M 干预问题的错配边界。

### S6 · 统计功效与种子预算规范化（治理级，需 ADR）
- 现状：所有配对矩阵 3 seed 且逐位相同（确定性模型下 seed 只作重放身份）；有噪声 L0（ADR-0015）后 seed 才有统计意义；
- 建议：为今后所有"随机"主张规定最小种子数与预注册检验（如 n≥10 seed + Wilcoxon 符号秩，α 与多重性校正先验固定）；把"3 seed 重放门禁"与"统计重复"在术语层永久分开。

## 二、不做清单（同样重要）

- **不**解封 Arc H1 / 运行 GEARS/scGPT/biolord（ADR-0047 No-Go 约束）；
- **不**用旧空间 target 再标定（ADR-0044 已消费禁用）；
- **不**为展示效果静默调参（AGENTS.md 反复冻结的负面基线红线）。
