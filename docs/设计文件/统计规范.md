# 统计规范（S6）

本规范承接《科学性提升方案-2026-09-11》S6 与 ADR-0048，约束 M-GBA 未来所有涉及随机性的科学主张。它只约束新主张，不回溯改写历史 artifact 与冻结结论（见 §5）。

## 1. 术语分离：确定性重放 ≠ 统计重复

- **确定性重放**（deterministic replay）：同一 seed 下逐位相同的重复运行。它只是重放身份与回归门禁，证明"管线可复现"，不构成任何统计证据。
- **统计重复**（statistical replication）：在噪声 L0（ADR-0015）等真实随机源下，不同 seed 形成的分布。只有统计重复才能支撑"效应""显著""一致"等推断性措辞。
- 禁止把 3-seed 重放矩阵包装成统计证据。确定性主链的 3 seed 逐位相同，seed 只作重放身份（ADR-0024 起的既定用法不变）。

## 2. 随机主张的最低规范

凡新的随机性主张（噪声模型下的效应、优势、稳定性），必须满足：

1. **样本量**：n ≥ 10 seed；
2. **预注册检验方法**：计算前固定检验方法（建议 Wilcoxon 符号秩或配对 bootstrap）；
3. **α 水平与多重性校正**：先验固定（多重比较建议 BH）；
4. **CI 与效应量同报**：区间估计与点估计必须同时出现，不允许只报 p 值或只报点估计。

不满足以上最低规范的运行只能登记为描述性或探索性结果。

## 3. 描述性结果标注义务

- 无量纲 reference 指标的距离/效应量（WP8 层间距离、CAR-M 效应量、空间 NAE 等）必须标注"描述性"；
- 任何"改善""一致""显著"措辞必须对应预注册判据；无预注册判据的一律降级为描述性表述。

## 4. 证伪对照义务

承接 ADR-0048：凡新的"通过/效应"主张，须配至少一个阴性对照——标签打乱、层置换、目标置换三选一或更多——证明管线本身不会产生假阳性。对照判据不成立时按负面结果原样登记（ADR-0048 对照 3 为先例）。

## 5. 与既有门禁的关系

- 本规范只约束新主张，不回溯改写历史 artifact 与冻结结论；
- 既有测试门禁（AGENTS.md §7）、数据登记门禁（ADR-0021）与预注册契约惯例不变；
- 历史 3-seed 确定性矩阵保持其重放门禁身份，不因此降级或改写。
