# M-GBA 核心原则

> 本文件定义项目不可被 MVP 裁剪破坏的核心。架构、计划和代码若与本文冲突，以本文为准。

## 1. 项目定义

M-GBA 的核心不是多智能体协作，也不是一个动态图通信框架，而是：

> 用可运行的计算模型表达生命从微观调控到宏观表型的逐层生成过程，并研究局部规则如何跨尺度累积为整体行为。

多智能体用于表达细胞个体，STEN 用于表达细胞之间的语义通信和组织拓扑。二者都是实现五层递进所需的子问题，不能取代项目本体。

## 2. 五层递进

| 层级 | 回答的问题 | 最小输出 |
|---|---|---|
| L0 基因与转录调控 | 细胞具有什么潜在能力，哪些能力正在表达？ | `TranscriptState` |
| L1 分子与蛋白状态 | 当前表达形成了哪些受体、酶和信号能力？ | `MolecularState` |
| L2 细胞个体 | 分子状态如何改变细胞感知、状态转换和行为？ | `CellState`、`CellAction` |
| L3 组织与语义拓扑 | 局部细胞行为如何改变相互作用网络和微环境？ | `TissueState`、动态图、场 |
| L4 有机体宏观表型 | 组织状态最终形成什么整体稳定性、功能或失衡？ | `OrganismState` |

每层都必须消费下一层的显式输出，禁止绕层读取“上帝参数”。例如 L2 不能直接读取 L0 的基因值并跳过 L1。

## 3. 三类信息流

### 3.1 上行生成流——项目主线

```text
L0 调控 → L1 分子状态 → L2 细胞行为 → L3 组织动力学 → L4 宏观表型
```

这是 M-GBA 的第一优先级。任何 MVP 都必须完整贯通这条路径。

### 3.2 层内交互流

- L0 内部是调控网络。
- L1 内部是分子状态转换。
- L2 内部是细胞状态机或策略。
- L3 内部是细胞通信、空间作用、STEN 拓扑和环境场。
- L4 内部是宏观状态和目标/约束。

多智能体主要存在于 L2，STEN 主要存在于 L3。

### 3.3 下行约束流

L4 不直接编写细胞答案，而是改变环境压力、资源边界或允许的调控范围；这些约束逐层向下作用，再由系统重新向上生成结果。下行流必须慢于上行局部动力学、可审计并受安全边界限制。

当前多速率 reference runner 只闭合 L2→L1 与 L3→L2 的相邻快速反馈；L4→L3 宏观约束尚未实现，不能把终点结局误称为完整反馈闭环。

## 4. MVP 裁剪规则

可以简化每一层的内部模型，但不能删除层或隐藏层间转换：

- L0 当前从六个抽象变量的确定性离散 GRN 开始，但不能退化为任意角色标签；抽象变量不得冒充真实基因。
- L1 当前使用显式翻译、降解和信号激活/抑制的粗粒度分子模型；它不是全原子动力学，也不能被 L2 直接绕过。
- L2 当前使用静息、激活、修复、应激和死亡五态规则模型；规则基线必须长期保留，不要求使用 LLM。
- L3 当前采用固定有向图，在节点级更新压力、资源和信号并聚合组织状态；动态拓扑和 STEN 后续增强。
- L4 当前采用只消费 `TissueState` 的即时指标、时间窗口摘要和冻结结局；反馈控制不属于该观察器。

简化模型的作用是验证架构契约，不是宣称生物真实性。

## 5. 最小科学证据

项目至少需要给出以下证据，才能声称五层架构已经工作：

1. 对 L0 的一次受控扰动，能够沿 L1、L2、L3 到达 L4。
2. 轨迹中能定位每次跨层转换，不依赖事后故事解释。
3. 跳过或冻结某一层后，宏观结果发生可测变化。
4. 相同微观配置和种子能够复现实验；不同种子形成可统计的分布。
5. 宏观指标不是直接编码进某个 Cell Agent 的目标答案。

“涌现”只用于描述没有被直接写入单个节点、却由大量局部交互稳定产生的宏观模式。
