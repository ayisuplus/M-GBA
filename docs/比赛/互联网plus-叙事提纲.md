# 互联网+ 参赛叙事提纲：M-GBA 跨尺度虚拟细胞平台

> 版本：v0.2.0（GitHub main，tag `v0.2.0`）
> 本提纲全部数字与结论均可回链到仓库内冻结 artifact 或文档，页内附回链清单。
> 科学表述受 `AGENTS.md` §4 约束：当前系统为 contract demonstrator / reference model，不宣称临床预测能力。

## 1. 一句话定位

M-GBA 是一个**自下而上五层跨尺度虚拟细胞平台**：从抽象基因调控（L0）逐层生成到宏观表型（L4），把"细胞治疗剂量决策"这类昂贵试错搬进可复现、可审计的计算机实验。首个落地案例是锚定 TCGA-BRCA 真实队列代理的 **CAR-M（CAR 巨噬细胞）虚拟剂量试验**。

## 2. 痛点

- 细胞治疗（CAR-T/CAR-M）研发周期长、成本高，剂量窗口窄：信号太弱无效，太强则细胞因子风暴等毒性风险。
- 临床前动物/体外模型与真实人体肿瘤微环境差距大，试错代价高。
- 已有计算工具多为单层黑箱（纯统计或纯图神经网络预测），无法回答"剂量如何在基因→分子→细胞→组织→整体层面逐级传导"。

## 3. 方案：五层跨尺度生成，而不是又一个黑箱预测器

```text
L0 基因/转录调控 → L1 分子/蛋白状态 → L2 细胞个体行为
  → L3 组织/环境场/拓扑 → L4 宏观表型（活力/损伤/炎症/稳态/恢复）
```

- 主生成流只走相邻层，任何层不能跳读"上帝参数"——每层职责可被单独替换、单独消融。
- CAR-M 场景：63 个细胞（15 工程巨噬细胞、10 野生巨噬细胞、20 肿瘤细胞、18 个 CD8 T 细胞）、固定组织拓扑、30 tick 多速率时钟（L0/L4 慢时钟）。
- 真实数据锚定：752 个 TCGA-BRCA 样本的旧 GAT 预测聚合为去标识化队列 profile（high/low/normal = 323/273/156），只作为免疫浸润代理，不含样本 ID、不是临床真值。

## 4. 证据页（只写真数据）

1. **冻结 21-run 因果矩阵** `matrix-143e5432d3876bbf`：7 条件 × 3 seed × 30 tick，群体 L0 扰动（15 个工程细胞同步钳制）经相邻层传播到 L4；0.7/1.0 剂量在所有层的最终状态距离均非零，且最大剂量距离大于 0.7 剂量（剂量方向性成立）。记录：`docs/实验记录/CAR-M-vertical-slice-2026-08-19.md`。
2. **修复基因敲低→L4 传播链**（WP8 参考矩阵 `matrix-7da4137aa39d5122`）：L0 修复敲低先改变 L3，再使 L4 损伤/炎症升高、活力/稳态/恢复降低，证明跨层通路真实工作而非空包装。
3. **层级消融非平凡**：L1/L2/L3 静态替换均显著改变 L4，其中 L2 静态替换产生最大终点差异——层与层之间是有职责的契约，不是直通管道。
4. **工程可信度**：77 项单元/契约/回归测试全绿；无第三方依赖，纯 Python 3.12 + 标准库；wheel 在空虚拟环境安装即可复现全部演示；每条 run 带 SHA-256 历史链，报告只从 raw artifact 字节级重算。
5. **现场演示**：`mgba demo-export` 生成单文件 HTML（内嵌数据、零网络，舞台双击即开），回放 4 个剂量条件的组织级动画与 L0→L4 级联检查器；playbook 带 digest，内容与冻结配置字节级一致。

## 5. 差异化叙事：诚实负面基线 = 虚拟临床前试验的核心价值

冻结矩阵的终末 L4 观测（3-seed 均值，seed 42 逐值一致）：

| 条件 | Δ 活力 | Δ 损伤负担代理 | Δ 炎症 | Δ 稳态 |
|---|---:|---:|---:|---:|
| `car_off_000`（无信号） | +0.0017 | -0.00003 | -0.0123 | +0.0044 |
| `car_affinity_070`（标准剂量） | -0.0111 | +0.0013 | +0.0296 | -0.0139 |
| `car_max_100`（最大剂量） | -0.0138 | +0.0015 | +0.0419 | -0.0188 |

**读法：提高 CAR 信号强度在当前规则下推高炎症，却没有降低最终负担代理，反而使其轻微上升。** 这正是虚拟临床前试验的卖点：

- 在 v0.2、零动物零患者成本下就暴露"高剂量毒性收益不成比例"的风险信号；
- 我们把负面基线**原样冻结进演示页脚与实验记录**，不为展示效果事后调参——可审计的研发态度本身就是差异化；
- 每条轨迹的 hash 链 + manifest = 可审计研发记录，评委/合作方可独立重算验证。

## 6. 科学边界声明（主动说清，防止误读）

- 按 `AGENTS.md` §4 分级：当前系统是 **contract demonstrator**（验证跨层接口与路径）兼 **reference model**（可复现简单基线）；不是 validated result。
- 全部指标为无量纲模型内代理，不对应细胞因子浓度或临床终点；L3 `tissue_damage` 混合肿瘤活力与免疫损伤，是模型内部代理。
- 不宣称：数字生命、已验证涌现、临床疗效预测、从表型反推真实 DNA。
- 当前 seed 不产生动力学差异，不做统计推断；多种子统计协议是路线图 E3 的后续工作。

### 评委 Q&A 预案

1. **"这和真实生物差多远？"** —— 层内模型是确定性粗粒度参考模型，TCGA 只锚定免疫浸润代理分布；我们卖的是跨尺度因果链路与可审计协议，不是单层预测精度。
2. **"为什么高剂量反而更差？是不是模型错了？"** —— 这是模型内一致、可复现的负面基线：信号推高激活与炎症，但现有规则未给出净负担收益。它指出了需要诊断的具体规则（五态 L2 累积），正是虚拟试验该做的事。
3. **"和 GNN/数字孪生项目有什么区别？"** —— 我们用 GNN 只做离线队列聚合（旧资产复用），生成主链是显式五层契约：每一层可替换、可消融、可审计，扰动能逐层追踪到表型。
4. **"数据可信吗？"** —— 所有结论只从冻结 raw artifact 重算；报告与演示带 SHA-256 manifest，任何第三方可用同一份配置字节级复现。
5. **"下一步怎么走向真实？"** —— 路线图明确：E3 多种子统计协议 → 反馈闭环 → STEN 动态拓扑；每一步都有预注册判据与消融对照，不跳级宣称。

## 7. 现场演示脚本（3 分钟动线）

道具：`artifacts/demo/mgba-carm-demo.html`（双击即开，断网可用）。

1. **0:00–0:30 开场**：打开页面，指认四色细胞（红=肿瘤、蓝=工程巨噬、青=野生巨噬、紫=CD8 T），点播放，baseline 条件下组织稳态运行。
2. **0:30–1:10 A/B 对比**：切到 `car_max_100 最大剂量`（tick 保持不动），组织画布上工程细胞行为立即可见差异。
3. **1:10–2:00 跨尺度级联**：点击 `eng-mac-001`（内环蓝点），检查器展示 L0 信号表达被钳制为 1.0 → L1 信号蛋白上升 → L2 激活/应激变化的完整级联。
4. **2:00–2:40 收尾一击**：拖到 tick 30，指 L4 炎症曲线在 `car_max_100` 终末点（0.1281）高于 baseline（0.0862），而损伤负担代理不降——"我们的系统在电脑里提前看到了剂量毒性风险，这就是产品的价值。"
5. **2:40–3:00 溯源**：指页脚 experiment id / history digest / playbook digest，说明每个数字都可由评委独立重算。
