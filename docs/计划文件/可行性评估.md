# M-GBA 跨尺度数字生命项目可行性评估

> 版本：0.2  
> 评估日期：2026-08-18  
> 决策：**以五层纵向递进为核心有条件可行；应按层级模型逐步升级，而不是降格为泛化多智能体系统。**

## 1. 评估对象

本项目要验证的不是“多个 LLM 能否互相通信”，而是：

> 基因/转录调控如何形成分子能力，分子能力如何约束细胞行为，局部细胞行为如何塑造组织，组织动力学如何产生有机体级表型，并接受较慢的宏观反馈。

这是一个跨人工生命、计算生物学、多智能体、图学习和复杂系统的长期研究方向。多智能体与 STEN 只解决 L2/L3 的局部个体和组织通信问题。

## 2. 总体结论

| 维度 | 判断 | 说明 |
|---|---|---|
| 五层软件架构 | 高可行 | 可以用可替换接口和简化参考模型逐层实现 |
| 五层科学真实性 | 分层可行 | 每一层均可逐步增强，但本科阶段不可能同时达到真实生物尺度 |
| 自下而上因果追踪 | 高可行 | 显式相邻层契约、事件日志和扰动实验即可验证 |
| 涌现研究 | 中等可行 | 需要多个种子、局部规则和预注册宏观判据，不能由单次演示证明 |
| 多智能体/STEN | 中高可行 | 是 L2/L3 的重要增强，但不是第一阶段前置条件 |
| 旧项目迁移 | 中高可行 | 已有 CAR-M 的 L2/L3 资产、GAT 数据和宏观统计可复用 |
| 长期研究价值 | 高 | 架构能够随课程学习逐层替换模型，适合作为两年研究主线 |

结论是：**项目愿景不需要被删除，但必须通过“每层简化、纵向不断层”的方式控制复杂度。**

## 3. 可行性来自哪里

### 3.1 软件工程上可行

五层不要求第一天就部署五个大型模型。每层先建立输入、输出、状态和参考实现，即可形成运行闭环。以后替换某层时，其他层和实验协议保持稳定。

### 3.2 现有资产不是零

旧 `car-m-virtual-cell` 已经提供：

- L2：多类细胞状态和行为规则；
- L3：细胞因子场、空间邻域、细胞交互和 GAT；
- L4 的一部分：肿瘤体积、吞噬率、极化比例等宏观统计；
- 可复现种子、单元测试和 E2E 经验。

真正缺少的是显式的 L0/L1、严格的层间契约、完整 L4 表型定义和跨层因果 trace。因此升级路径应围绕“补齐和解耦五层”，而不是另起一个普通 Agent 框架。

### 3.3 硬件上有充分余量

当前工作站已验证 RTX 5090 32607 MiB、PyTorch 2.7.0+cu128 和 CUDA 可用，足以支持后续 GNN、局部模型和多 Agent 实验。硬件不能解决模型定义和科学验证问题，所以前期优先做 CPU 可复现参考模型。

### 3.4 学习时间与架构匹配

项目可以让大三、大四课程分别增强不同层：概率与动力系统用于 L0/L1，机器学习用于 L1/L2，GNN 和多智能体用于 L3，因果分析与复杂系统用于 L4 和跨层实验。这比现在一次性堆叠所有前沿框架更可行。

## 4. 必须守住的科学边界

- L0 抽象调控网络不是 DNA 序列。
- L1 粗粒度状态不是全原子蛋白动力学。
- L2 使用 LLM 不自动意味着细胞具有生物智能。
- L3 的 Agent 状态趋同与 GNN 过平滑不能直接等同。
- L4 指标聚合不自动构成涌现。
- 从 L4 反向搜索可行配置不等于逆向编译真实 DNA。
- 项目第一阶段验证架构和跨层因果，不做临床预测。

保留这些边界不是削弱愿景，而是让每次升级都能形成可信证据。

## 5. 最关键风险

| 风险 | 影响 | 控制方式 |
|---|---|---|
| 五层只是命名，实际计算仍集中在单层 | 项目创新失效 | 强制相邻层接口、禁止跳层、E0 完整性测试 |
| 简化公式被误当作生物模型 | 科学结论不可信 | 标记 reference/placeholder，只用于契约测试 |
| L4 预先写入想要的答案 | 伪涌现 | L4 只消费 L3 状态；宏观判据事先冻结 |
| 中央 LLM 直接控制微观行为 | bottom-up 被破坏 | L4 仅施加低频环境/安全约束 |
| 同时升级五层导致无法完成 | 工程失控 | 一次只替换一层，简单模型长期保留为基线 |
| STEN/LLM 热点反客为主 | 项目再次漂移 | 所有增强必须报告其对跨尺度结果的贡献 |
| 调研文献含二手来源和错配链接 | 论文风险 | 正式写作只使用核验过的原论文和官方资料 |

## 6. 旧资产迁移策略

采用由中间向上下扩展的迁移方式：

1. 把旧 Cell/Field 行为抽象为 L2/L3 插件，不立即重写。
2. 在其下新增 L0/L1，让部分细胞参数由表达和分子状态产生。
3. 把旧统计重新定义为 L4 `OrganismState` 的领域指标。
4. 为每次 L0 扰动记录经过 L1/L2/L3 到 L4 的路径。
5. GAT、TCGA 和 React UI 在层间 DTO 稳定后接入。

## 7. 决策门

1. **G0 架构守恒**：五层对象、相邻契约和核心原则进入代码与测试。
2. **G1 纵向贯通**：简化参考模型完成 L0→L4 trace。
3. **G2 跨层因果**：L0 扰动和层级消融产生可复现 L4 差异。
4. **G3 群体动力学**：多 Cell 局部交互产生稳定宏观模式。
5. **G4 模型升级**：逐层引入 ML/GNN/STEN/LLM，并与参考模型对照。
6. **G5 涌现主张**：只有预注册判据、多种子统计和消融支持后才使用“涌现”。

## 8. 最终建议

进入项目，但优先级调整为：

> **五层契约与纵向 trace > L0 扰动实验 > 群体动力学 > 反馈闭环 > STEN/GNN/LLM 增强 > UI 与规模展示。**

本科 MVP 应缩小每层的真实性，而不是删掉层级。M-GBA 的长期价值正是同一套跨尺度骨架能够随着学习逐层成长。
